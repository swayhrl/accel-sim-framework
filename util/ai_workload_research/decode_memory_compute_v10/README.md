# V10 tools
The root controller/source set, native_counters and native_b2 are separately frozen executed versions. Do not rerun: all GPU work ended. Their SCIENCE_CONTRACT.json files bind exact source bytes.

The initial conservative backup-column parser and the B1 terminal-monitor STOP are retained. native_b2 adds strict <=6s finished-context drain; it does not waive PID identity/unknown-compute/resource failures. The old monitored STOP is not rewritten as a complete run.

analyze_v10.py is CPU-only postprocessing: it accepts lossless archived raw, independently rechecks full private returned prompt/output hashes and lengths, reads completed CSV audits, regenerates counter/resource summaries and local proxy statistics. It requires lawful access to the privately indexed original completions. NUMERIC_BOUNDARY_ANALYSIS.json and cpu/COST_LEDGER / COPY_PATH_REVIEW include their own source manifests and exact lossless detail archives. No analysis script initializes CUDA.

85 inherited/new CPU tests plus the dedicated schema and terminal cases are recorded. No actual GPU call is counted as native formal latency in V10; V9 remains native curve authority.
