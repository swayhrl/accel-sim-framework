# R81 source capability map

This is a capability audit for the bounded R81 experiment, not a novelty claim. The [Round 08 literature authority](https://github.com/swayhrl/accel-sim-framework/blob/214b30039cc579c28457cb17bfbd7e9d88d00fcd/docs/vm_tlb/literature_notes/awma/rounds/2026-09-27_ROUND_08_PARALLEL_PROBLEM_DISCOVERY.md) is the reading record.

| Source | Established capability | R81 treatment and limit |
| --- | --- | --- |
| [XGrammar-2](https://arxiv.org/html/2601.04426v4) and pinned `xgrammar==0.2.8` wheel | Grammar compilation, online mask generation, cross-grammar reuse and CPU mask work that can overlap model compute. | Actual JSON-schema matchers generated every R81 legal set. The library's mask work is not claimed to skip LM-head weight rows. Wheel SHA and schema/tokenizer hashes are bound in `INPUT_RUNTIME_BINDINGS.json`. |
| [FlashSampling v2](https://arxiv.org/html/2603.15854v2), Algorithm 1 and Appendix D | Tiled LM-head computation with selection before writing a full logits tensor; masking is mathematically supported by `-inf` and zero-mass groups. | A1 is an SM89 BF16 greedy adaptation of the fused tile idea. It is not a reproduction of the paper's Gumbel sampler or implementation. Its slower result does not refute a more optimized FlashSampling implementation. The v2 paper itself leaves some masking/top-k implementation extensions to future work. |
| [Kestrel pinned source](https://github.com/m87-labs/kestrel/blob/f61d3c7c6a8380e705a984f1e1767693464e27bd/kestrel/models/moondream/text.py) `lm_head`, blob `50ac9a5da9cd22efc8d62a20ab5d47eff1b4b2e4` | The optional `indices` path selects `lm_head.weight[indices]` and bias before linear projection. | A2 ports the already known indexed-head capability to a sorted B4 union with reusable gather storage. It measures the union/gather cost; it is not a claim to invent indexed projection. |
| [VocabTailor](https://arxiv.org/html/2508.15229v1) | Hybrid static task and dynamic input-related vocabulary selection with on-demand components. | Quality-oriented approximate selection is different from exact grammar support. R81 never removes a legal token by probability or frequency. |
| [FlashRec 0.1.0 documentation](https://pypi.org/project/flashrec/0.1.0/) | Describes projection only over its SID token range plus fused trie-constrained selection. | A fixed SID range is a relevant prior restricted domain. The R81 audit did not verify arbitrary per-request dynamic grammar support in FlashRec source, so it makes no claim about that capability. |

R81's A3 is an original bounded Triton direct-index prototype over all current legal IDs, with one launch per identical-mask group. A1/A2/A3 are software capability probes with one frozen configuration each. No third-party source file was copied into their implementations. Their numerical and complete-generation results are valid only for the pinned Qwen2.5-0.5B BF16/SM89 workload and authored structured fixture.
