# ROB1 controller disk policy update

Status: **SOURCE_PREPARED_NOT_EXECUTED**. Implements the user's explicit disk-policy change supplied by the coordinator: actual output mount free space must remain strictly greater than 5GiB; equality or less prevents new build/sim and calls for controlled cleanup of one's own active task. This update grants no new build/runtime permission and does not retroactively accept any old refusal or failure.

Only `implementation_r1/bounded_cpu_build.py` disk admission/monitor/final-boundary conditions and disk receipt fields change. `free_bytes()` still measures `os.statvfs(OUTPUT)` using available bytes, so the actual isolated output/TMPDIR filesystem is checked. The prior local 2GiB minimum becomes 5GiB. Active/final checks now reject `free_bytes() <= 5 * 1024**3`, including exact equality. An active rejection follows the existing unreaped owned-child/group cleanup; the cleanup implementation is unchanged. After a successful reap it still only inspects/reports and never signals an old group.

The existing 512MiB sampled output ceiling, 128MiB file limit and admission reserve remain. Admission requires at least `5GiB + 512MiB + 128MiB = 6,039,797,760 bytes` (5.625GiB), allowing the registered maximum writing plus the existing reserve above the new hard floor. This is a bounded write-footprint assessment, not an extra 10GiB condition or a claim that a fresh build's actual peak has been measured. Runtime hard-stop is the strict 5GiB boundary; the same output/file/log limits remain. Receipt fields expose the hard floor, start reserve and strict-greater-than rule.

Core `b1077667`, flags, commands, ABI target, one job, timeout, clean environment, memory/OOM/IO/ownership rules, source checks and cleanup are unchanged. The original preparation records and standalone helper PASS remain historical and unmodified. The parent still holds the old controller digest in its role contract and must refreeze the new controller SHA and update its own CPU admission/output-budget registration before any execution. No controller, fixture, compiler, test, simulator, resource sampler or process inspection was run for this update.
