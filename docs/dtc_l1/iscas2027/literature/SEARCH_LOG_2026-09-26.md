# 检索与取文记录｜Round 1

记录日期：2026-09-26。项目证据边界截至2026-09-25；本轮额外检查了2025–2026年的公开研究。以下为检索路线与结果摘要，不冒充逐分钟浏览器历史。

## 1. 检索范围

主题：GPU L1的Tag/Data解耦；非阻塞缓存与MSHR组织；请求重排/缓存旁路；warp并发度与缓存局部性；L2/内存服务压力；近期AI/LLM中有关缓存仲裁、在途合并及节流的体系结构工作。

不预设“最近论文一定最相关”。从DTC当前结构向前追溯2003/2005等先例，再检查2010年代GPU方法和2025–2026近作。软件KV-cache、通用应用缓存、纯模型压缩等同名结果不进入主比较集。

## 3. 来源等级与页面核读

优先作者机构站点、出版社页面与作者预印本；通用索引只作定位。PDF关键架构图/表使用页面图像查看，不只依赖文字解析。本轮核读图表集中在：NuRAPID架构页、V-Way操作页、P03设计/配置页、MRPB绕行规则与配置页、MeDiC优先级/方法页、Poise结构与方法页、SACAT首页、RPAWS算法/配置页。各笔记明确其范围，不将其扩写成所有图表已审。

## 4. 取文失败与保留缺口

- CCWS：取得原文首页/摘要，后续页面读取不稳定。状态保留PRIMARY_FRONTMATTER，不借MRPB等的引用补作精读。
- DL-MSHR：作者目录确认条目；链接PDF多次读取超时，出版入口未提供可用正文。保留METADATA_ONLY。
- MiCache：可核索引标题和DOI，未取得足够正文。保留METADATA_ONLY，作者列表未完成第一方复核。
- 部分原文下载到运行容器失败，但浏览工具可读取作者页面/PDF；笔记以实际可读来源为准，不声称本地归档了这些PDF。

未取到全文不意味着论文未披露，也不意味着与DTC无关。

## 5. 已纠正的书目/解释风险

1. SACAT卷期是2017 TPDS，DOI带2016；不误记为2021。
2. LLaMCAT作者稿页首标注ICPP2025；arXiv版本出现时间不是唯一出版年份依据。
3. MeDiC的2018回顾明确回指PACT2015；不按两项独立创新计数。
4. Poise使用回归预测与运行时控制；不写成未经核实的决策树算法。
5. P03中的RC是局部性/复用计数；与DTC Ref_cnt的既有消费者计数分开。
6. RPAWS发射侧忙闲不是直接的L2/DRAM压力遥测。

## 6. 局限

本轮没有完成所有近年顶会逐卷检索，没有引用网络数据库的总命中数作为覆盖证明，也没有执行任何论文复现。结论是“获得一组有来源的相关工作与明确缺口”，不是“相关工作全部查完”。所有远端新增内容均为文本笔记；没有修改主线模拟器或执行合同。
