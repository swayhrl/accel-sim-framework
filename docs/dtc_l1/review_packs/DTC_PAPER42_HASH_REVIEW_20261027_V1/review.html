3MM / GEMM

已观察事实

  • Within DTC, hash reduces tag evictions, new line/lower read requests and accepted L2 read bytes by roughly78-81%; cycles decrease about23-24%.
  • Both CM/CH and DM/DH have zero modeled DRAM reads in these exact input runs. This is consistent with their reused small working sets and memcpy-initialized L2, not ideal-L2: -l2_ideal=0 and -gpgpu_perf_sim_memcpy=1.
  • Hash preserves bank bits; the finite OO terminal output does not print Tag-bank conflict or duplicate-after-eviction counters. They are unavailable, not zero.

仍不能确认

  • Conflict-versus-capacity miss split without a shadow/tag reference model.
  • Per-request repeated lower fetch counts and exact causal portion of the speedup.
  • Ready-conditioned mean differences are not causal cycle savings; they rise after hash here while whole-input cycles fall.

支持的解释：Source changes only fixed row indexing within each design; fewer row replacements/new requests strongly support a Tag placement/reuse mechanism, with reduced L1-to-L2/interconnect pressure. This is not direct measurement of bank collision reduction or redundant unique-data transfers.

ATAX / MVT / BICG

已观察事实

  • Selected full captures have16 CTAs in each256-thread kernel on64SM; at most16SM can execute blocks for a kernel simultaneously.
  • After hash, DTC sends fewer L2 read sectors than CH but issues more DRAM read atoms: the accepted L2 read-miss fraction is higher.
  • The strided matrix traversal kernel accounts for over93% of DH whole-input cycles.
  • OO completion-service post-ready means remain a few cycles; global time-mean PIB occupancy is small, but includes idle SMs and does not prove zero PIB-full episodes.

仍不能确认

  • Exact allocation versus timing/reordering contribution to the higher L2 read-miss fraction and DRAM reads.
  • Whether a particular finite service port is the critical limiter; lack of a printed stall category is not a zero count.
  • Physical-GPU performance, area-matched superiority, or transferable numerical values.

支持的解释：Remaining adverse cross-design performance is associated with low CTA concurrency, the strided kernel, L2 read residency/miss behavior and downstream backpressure. Hash repairs a substantial Tag mapping effect but does not eliminate the downstream work or the different modeled C/D service/capacity constraints.
