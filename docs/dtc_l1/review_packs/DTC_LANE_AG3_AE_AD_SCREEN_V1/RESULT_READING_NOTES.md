# How to read the final evidence

FULL_MATRIX.tsv records all six reservations, including consumed reservations, actual fork/exec starts and unstarted rows separately. An exclusive RUN_START record is a conservative budget reservation; ENGINE/FORK_CHILD.json is the direct actual-child evidence. Failure after a real fork consumes that attempt even if exec, loader closure or kernel initialization fails. CPU fixture synthetic starts are isolated outside raw/attempts and are never included in this count.

Only performance_accepted=true in a full STRICT.json supplies an application cycle count. Raw prefixes, live effective-option checks, early loader closure, normal-looking resource samples and successful CPU probes do not supply a partial performance PASS. An observed kernel_name header count is a diagnostic, never a replacement for full instructions/CTA/commands and terminal closure.

PER_ARM_METRICS.tsv uses the published METRIC_DICTIONARY.tsv. Integer sums and exact rational means retain their denominators. A missing field is UNAVAILABLE, and a zero denominator is UNDEFINED_ZERO_DENOMINATOR. AD ready-conditioned statistics are descriptive under their changed condition and receive no BASE subtraction. ON-only fanout/span/own-dependency details remain separately typed in TYPED_MECHANISM_RESULTS.json; OFF absence is never filled with zero. Full public raw metrics are retained even when a selected table cannot compare them.

For a measured AD-only object, the table marks MEASURED_ON_ONLY_PER_SM and points to the actual per-SM diagnostic instead of inventing a scalar aggregate. The coordinator shell exit code is not the scientific outcome: caught cohort failures are recorded as STOP in COHORT_TERMINAL.json. Use that terminal status and each STRICT.performance_accepted field.

The frozen strict receipt retains a legacy JSON property named AC_pipeline_diagnostic. In AG3 its producer is strict_screen.pipeline_contract: AC frames are explicitly rejected; AD ON produces PASS_AD_ON_ONLY_DIAGNOSTIC, and BASE/AE produce UNAVAILABLE_OFF_NOT_PRINTED. The final typed report exposes this object as ON_only_diagnostic. This legacy property name does not indicate inclusion of AC or its160KiB/SM banks.

ACTUAL_LOADER_LIFECYCLE_EVIDENCE.json is a bounded selection from actual early/system-call maps records, linked by SHA to complete logs outside Git. Initial executable/interpreter mappings, cache presence, explicit cache disappearance and startup closure are separate observations. A successful early closure is only an initialization result; full-lifecycle identity also requires the engine terminal and post-run frozen-file checks. All CPU negative tests are identified as CPU tests; no deliberate identity corruption is injected into a scientific attempt.

Resource WARN is not performance acceptance or automatic disregard. RESOURCE_TIMELINE.tsv and RESOURCE_WARNING_SUMMARY.json preserve the actual decision samples; full process/cgroup/FLOCK context remains in the new raw root. Isolated global swap pages do not establish this simulator's paging. Own major faults, cgroup swap/OOM changes and sustained pressure follow the immutable AG3 R2 rule. Historical AA5 follows its own original rule and remains unchanged.

Own RSS and major faults are discrete /proc observations. The frozen engine does not capture final wait4 rusage; final ru_maxrss/ru_majflt are therefore UNAVAILABLE. A largest sampled RSS is not a guaranteed exact peak, and zero observed major faults is not a proof about the unobserved final sampling interval. Do not copy AA5's final rusage fields into AG3.

ADMISSION_TIMELINE.tsv retains both independent admission samples and the separate final pre-fork check. FLOCK_TIMELINE.tsv groups only consecutive identical observed holder/identity/classification states, preserving first/last observation and sample count; a missing observation breaks the interval. This is a compact derived report, not proof about time between samples. Full fdinfo and every sampled process/FLOCK context remain in the indexed raw snapshots. Locks outside the reviewed DTC set are explicitly distinguished from reviewed execution authority.

The current goal ends only after its registered cohort has a terminal outcome, final evidence is published/read back, and its children/execution FLOCK are gone. Proposed future work and editorial recommendations are not an execution queue or an additional authorization.
