# AG3 production mapping/lifecycle closure

The AG2 mapping_roles.py is copied byte-identically. Static readelf PT_INTERP/recursive DT_NEEDED closure (never target --list) freezes main ELF, interpreter, exact dependencies and /etc/ld.so.cache; dash/cat have separate per-exec role registries. Every role has canonical path, SHA, dev/inode, full stat identity, source and pre-fork freeze time. No cache-absent positive qualification, path wildcard, ignored nonELF or post-run additions.

Only the wrapper's own fork child calls PTRACE_TRACEME; no attach API. Before exec, a Linux x86-64 seccomp TRACE filter stops mmap/mprotect/munmap/mremap/shmat/shmdt/pkey_mprotect. The parent captures complete maps at each relevant syscall entry/exit; fork/vfork/clone/exec/exit events cover every owned thread/helper. No syscall is emulated or changed. Other syscalls continue normally. NO_NEW_PRIVS and EXITKILL apply only to the owned subtree. All early cache appearance/unmap must be observed and confirmed; no late-sampling exemption. Ordinary runtime mappings are checked too, not just first startup. Unknown files, changed IDs/SHA, writable/executable loader data and unexpected exec reject. Post-start registered ELF disappearance rejects; cache unmap is explicitly logged, and exec starts a separately frozen image epoch. Failed helpers/unfinished startup also reject. Evidence bound250000 complete snapshots/run; overflow STOP, never truncate acceptance.

CPU fixture uses the same system PT_INTERP and fresh libcudart.so but never calls GPU/model APIs. It creates/joins a thread and popens real dash/cat reading an AG3-owned tiny data file. The exact production guard is exercised for natural exit, unknown actual file mapping, actual writable private cache mapping, timeout, fork/map-reader/observer injected failures, forced stop and confirmed-file disappearance rejection. The latter disappearance is a declared parent validator fault injection, not a claim to have physically unmapped libcudart. Kernel child-stop-before-parent-fork ordering required quarantine until the parent's event confirms ownership; first failure was retained, no foreign process resumed/signalled.

The run_one CPU closure exercises input stat, actual config copying, exact argument capability, exclusive start/budget record, real process engine, final resource/authority, outputs and cleanup. Only publication/admission/GPU-strict adapters are mocked for this CPU fixture; it is explicitly performance_accepted=false/cycles UNAVAILABLE. Scientific gates and strict parser are independently tested, then must pass real publication and first budgeted simulator identities. CPU evidence never claims an actual simulator launch or full-lifecycle simulation PASS.

Production invocation requires --dispatch, published immutable registration/fetch-back and independent source/Core/ELF closure. Each six-point UUID is reserved once, before its only fork/exec; failures STOP, no resume/retry. CPU fixture synthetic records are isolated from real attempts. All exceptions preserve records and own-child cleanup; an independent pidfd OOM monitor runs every0.25s including during hashes. Resource/capability/prelaunch failures are not converted to performance results.

Scope: controlled Linux x86-64 same namespace, frozen SASS replay plus known shell/cat helpers. New plugins/executables/mapping types are not auto-qualified. Hardware/native/load numeric correctness, other hosts/architectures and legal no-cache systems remain UNQUALIFIED. Actual simulator initialization is first verified in its registered, counted attempt, never a canary.
