# CPU coverage and preserved limitations

生产`run_one`路径的正例调用固定无GPU C++程序，未调用正式`--dispatch`。publication与初末准入是明确CPU适配器，GPU strict输出为false/UNAVAILABLE，真实guard/loader/descendant/mapping/文件身份路径被执行。实际资源快照照实保存；CPU适配器不能用于任何性能资格。

第一次`runner-first.stderr`在真实FINAL_PRE_FORK资源门槛失败，未fork。此记录保留；为验收后续CPU包装路径，第二次使用明确标注的CPU初末准入适配器，生产资源规则没有修改。第二次独立目录中完整CPU包装自然exit0，其14项结果不能当作正式性能准入通过。

其余实际生命周期与generation覆盖沿用AG5修复并在本生产guard重新运行：真实clone/fork/exec/exit、reader helpers、三次以上10秒周期observer、子先stop/observer先于父事件的真实重排、缺事件2秒超时、STOP pending清理、合法parent先reap/child后stop。generation输入是synthetic，真实kernel PID reuse与真实性能仍UNAVAILABLE；旧不安全ptrace尝试在适配器中被记录并阻断，不产生外部信号。

mapping parser、R2政策及strict解析器保持原字节；正常系统dynamic linker实测cache出现与unmap。缓存内容/路径/设备/inode/角色、未知exec/map、writable cache等拒绝保持。新配对BASE gate使用CPU synthetic STRICT收据，含明确CPU标记；这些收据不在正式`raw/attempts`，不成为性能UUID、预算或BASE。

新正式runtime/loader/cache与702项源码当前身份freeze和511个原trace完整SHA受资源gate阻止，尚未运行。复制的历史身份清单置于`historical/`或`HISTORICAL_`命名，不能视作本批新freeze。当前ELF未执行；首次真正初始化只能发生在经完整发布/准入后的第一个预算内BASE。

不重复运行未改Core的旧AE/AD CTests，不建立新微架构或Linux通用监督框架，不改变模型及科学合同来降低资源或等待开销。
