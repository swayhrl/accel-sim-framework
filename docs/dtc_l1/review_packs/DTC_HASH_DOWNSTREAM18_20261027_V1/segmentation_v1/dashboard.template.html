需要保留的边界

快照区间流量按事件发生时间统计，可能来自上一段的未完成请求。多个子分区的受阻事件能在同一周期同时发生，不能直接当成应用停顿周期。

PQ 入口受阻减少并不等于 DRAM 调度等待变短；PS 加速也不能单独定位带宽、bank/row 或请求排队。

先完成只读比较，再考虑最小插桩

  1. 优先导出 DRAM 请求等待累计和 / 完成数、队列长度积分、服务 busy cycles。
  2. 仅在仍无法解释 DH 劣势时，补 DTC PIB/OO、Tag、下发与完成服务的累计计数。
  3. 只有循环位置仍关键时，补少量 kernel/CTA/warp 的 PC 和迭代前沿。

以上是方案，不含新编译或新模拟。真实模拟验证需另行批准；当前运行的二进制、配置和 controller 未改动。
