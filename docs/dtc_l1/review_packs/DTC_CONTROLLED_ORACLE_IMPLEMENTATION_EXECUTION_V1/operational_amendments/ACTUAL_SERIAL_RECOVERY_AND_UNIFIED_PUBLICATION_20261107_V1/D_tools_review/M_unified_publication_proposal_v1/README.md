# Minimal Main-owned unified publication proposal

This is source only. It has not been started, installed, or used to run Git. No scientific registration/model/dispatcher/owner operation is present.

The wrapper privately loads the exact prior L1 publisher and keeps its existing Main enable file, common `control/publication_v1/LOCK`, linked-worktree checks, explicit narrow staging, no-overwrite timestamp leaves, push/ls-remote/fetch/remote-manifest byte readback. Its sole index change selects `CLEAN_UNIFIED_BACKGROUND_INDEX`, leaving the old default/background indexes untouched. Main must prevent an obsolete publisher from competing for the same publication responsibility; this proposal itself never stops another process.

The bridge exposes the existing `snapshot(native_base,matrix,out)` API. For this bridge `--native-base` is the new Main-owned binding JSON path, not a directory. It calls the independently reviewed dual-root consumer. Main must first populate exact approved external evidence references in a new binding file using its actual reviewed final release. No CPU draft receipt grants acceptance.

The trigger hashes the fixed128 rows' actual statuses, classifications, raw/result SHA/UUID/cycles/pair state and validation errors, excluding time and progress noise. Thus new accepted/negative/HOLD/running state can be published at the next 30-minute gate; unchanged polls do not commit. The previous publisher lifecycle calls its trigger `closed_fingerprint_sha256`; PUBLICATION_SCOPE adds an explicit fingerprint contract and preserves S's real result digest under `scientific_closed_result_fingerprint_sha256`. The source/result pins remain unchanged. Historical leaves are never overwritten.

Main may reuse the old exact CLI flags, with the wrapper as executable, the bridge as `--consumer` plus its SHA, the caller binding as `--native-base`, and a new private `--state-dir`. `--publication-enable` remains required for any Git call. Without `--watch`, only one cycle is attempted. With `--watch --poll 60`, the old due function enforces 1800 seconds between changed-state publications. This document does not authorize or start that process; Main supplies its formal caller release and checks D review.

Limit: this proposal deliberately reuses old publisher Git semantics. If push succeeds but readback fails, it preserves fail-closed reconciliation behavior rather than silently advancing state. The derived package is bounded to128MiB and32MiB/file. It does not publish raw logs or simulator binaries.
