# AG4 bounded external lifecycle repair

AG3 sampled authority before consuming available ptrace events and only accepted the registered root. Its stopped candidate4042390 was never accompanied by a recorded parent event or next exec. Pre-exec reader-helper ancestry remains an inference for that historical PID; the failed Gaussian remains failed.

AG4 drains available wait events before sampling, with a finite256-event batch bounding observer starvation. Ownership uses the actual PTRACE_GETEVENTMSG fork/vfork/clone event from a PID/start_ticks-confirmed parent. The child PID/start_ticks, tracer, PPID or same-thread-group relation must match. Inherited image state comes from that exact event parent. Every exec opens a separately frozen mapping epoch; mapping role/content/inode checks are unchanged.

An observer-first traced stop becomes PENDING/QUARANTINED, never PASS. Its fixed confirmation window is2.0 monotonic seconds. No child resume or signal is permitted from PPID/path/argv resemblance alone. Missing proof, identity contradiction or timeout fails closed. STOP cleanup drains real parent events before signalling exact confirmed unreaped instances; CPU pending-stop and timeout cases verify this path. Unresolved cleanup is reported as failure rather than zero live children. EXITKILL remains set on owned tracees.

CPU fixtures use real system dynamic loader, pthread and repeated dash/cat readers through the production guard and observer. Declared wait-order adapters hold real kernel parent events to exercise observer-first, child-stop-first, missing-event timeout and pending cleanup. Synthetic snapshot/PID mutations test foreign and wrong-instance rejection. They create no simulator or performance result. Prior CPU adapter/expectation errors and original failed run receipts are retained in new raw, never rewritten in AG3.

No Core, binary, quota, switch, clock or metric definition changed. AG3s12-file role closure is frozen again before any target start; nonELF files are never blanket-exempted. The five-point budget/imported-control logic is a new cohort protocol, not recovery of any old dispatcher.
