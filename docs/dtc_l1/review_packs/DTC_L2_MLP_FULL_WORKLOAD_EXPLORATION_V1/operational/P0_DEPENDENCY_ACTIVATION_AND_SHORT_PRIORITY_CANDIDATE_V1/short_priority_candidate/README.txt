RESERVED immutable token using the existing fsynced same-directory no-replace

and never permits a second exception attempt for that target. After unchanged

Main-only restore API
one_shot_owner.restore_in_owner() disables the exception, restores the original
E method under its same lock, and unwraps its observer if still outermost.
A newer outer wrapper is not overwritten. Existing jobs, tokens and bindings
stay intact. Restoring priority is not a model interruption or budget refund.
No SIGSTOP/SIGCONT or memory guard is included: STOP retains RSS and unchanged
supervisor stale-producer deadlines still make long pauses incompatible.
