# Eleven independent incident recovery trial identities

This is a frozen identity/contract draft. It registers no grant, launches no
model, changes no original result, and does not add a program to primary350.
Every proposed trial has `cycles=None` until an actual independent execution.

Incident ID: `DTC_BPF_SCOPE_SELFLOCK_CADENCE_20261029_0031CST_V1`.
The selection is exactly the eleven `same_birth_live=True` identities in the
pinned independent DELTA. Five hybridsort and six SYRK points map one-to-one
to the same old cohort stem with suffix `-IR1-V1`. No performance, elapsed-time,
PASS status, or configuration preference is used to choose recovery points.

Each draft keeps the original Core, Framework, binary, input/binding/trace
scope, configs, runtime files, full expected options and simulator argv.
Canonical host_cpu remains None. Only cohort, scientific role, and the new
incident lineage differ. Scientific projections use the existing Main science
key contract and sorted compact JSON SHA256; the proof also checks the complete
expected-options dictionary and native argv independently of that projection.
Current resource caps are copied unchanged. Any later official forecast/cap
amendment must preserve science and full lineage and must have its own evidence.

Role: `INCIDENT_RECOVERY_PERFORMANCE_TRIAL`. Lineage pins old cohort, UUID,
PID generation, canonical spec SHA, negative RESULT SHA, DONE SHA, compressed
and uncompressed raw SHA, incident evidence SHA, and science projection SHA.
`new_grants=1` in lineage is the planned independent per-trial budget contract;
it is explicitly marked `planned_grant_not_actual_authority=True`. Actual
grants and starts are zero. Refunds, old-UUID reuse, and automatic retry are
false/zero. Raw logs were not rescanned; raw SHA provenance is the original
negative DONE and the already independently verified incident archive.

All original eleven failures remain unaccepted and SOURCE_KEEP, with immutable
copies of their canonical spec, negative RESULT, DONE and INTENT inside each
draft identity directory. The original active files were only read. Drafts
neither replace old failures nor count as accepted recovery results.

The existing user Goal and explicit incident-recovery direction authorize
ordinary execution engineering; this draft invents no extra per-trial user
permission gate. Main still performs any necessary independent registration,
official resource qualification, scheduling and complete strict/archive
acceptance. The four observation canaries are handled first. This draft retains
the old observation contract and adopts no BPF setting automatically.

Recovered trial results remain separately labelled and excluded. Adding them
to effective35 GM, parent-result selection, or a final adopted result set needs
explicit user confirmation. Neither this draft nor eventual trial execution
silently authorizes validated union.
