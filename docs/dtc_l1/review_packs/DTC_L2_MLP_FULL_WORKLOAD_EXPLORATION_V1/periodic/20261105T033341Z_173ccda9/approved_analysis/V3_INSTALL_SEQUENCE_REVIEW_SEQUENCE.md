# Main V3 installation: interface order and rollback

This is an interface contract for an **unexecuted** Main installer. It approves no future draft and performs no production action. Frozen E14 files and all old sources remain unchanged.

1. **Read-only preflight.** Pin the staged five runtime sources, policy389, IR-scope/memory helpers, final QA and actual native/164 byte readback. Check the actual Main PID/start, parent lease, scheduler frame, pool/claims/aging/SYNC/Tiny/registry identities and previous V2 routes. Reconcile q360 without granting/refunding. Account honestly for concurrent old natural completion and preserve existing UUIDs/science. Existing pre-exec claims must be drained; never assume aging.lock covers a previously returned decision.
2. **Real release receipt, outside authority EX.** In the actual Main thread call `extra.capture_release_prerequisite(frame, main, immutable_path)`. It must replay all four real V2 accepted engineering chains and their archives; missing any point is HOLD before mutation. Bind its path/SHA into immutable V3 cfg and the operational record. CPU fixtures are not release evidence. Capture/verification, `registered/canonical`, and full strict/archive replay must never execute inside an authority mutator.
3. **Close the primary staging window.** Primary points already exist in the real MATRIX; assigning the V3 worker is potential exposure even before adding IR view rows. Install a same-owner pre-arm fence and set `ever_exposed` **before** any new selectable worker assignment. A cached selected unused call must defer without writing an INTENT/route claim or consuming credit; spent/unknown must preserve, and old engineering4/nonselected calls delegate exactly. Any integration mechanism must also prevent the B-install assignment window from bypassing this fence. An additional narrowing staged-readiness check is acceptable only if it retains every real E readiness check; a fake ready boolean is not.
4. **Wire mandatory routes while unarmed.** Register only the exact V3 operational record using a pure locked-q mutation. Install E first: `install_on_frame(frame, cfg_path, engine.assert_parent_lease, main=main)`. Install B second with the real, source-qualified `consumer_check`. Confirm actual frame-private `consumer.safe_finish` reaches the new outer route, the previous V2 safe remains underneath, and original load/finish/archive/put/global entry sources are untouched. The installer itself must not call a worker or native launch.
5. **Finish scope, then expose IR last.** Forward-append memory43→54 using the qualified pure-locked-q helper and retain old config/record preimages. A memory append may precede route wiring, but **IR runtimeview exposure may not**. Install the outer adaptive IR-strip adapter before publishing the IR reader: the existing engineering4/R2 adapters must receive exactly their old view. The real primary350 MATRIX/SCOPE, statistical parents and GM remain unchanged. The optional runtime view becomes355→366 only when mandatory routes and scope are ready. No new grant occurs.
6. **Commit once.** Check identities, source/QA/Gate/config hashes, old result/UUID/science preservation, current operational/memory records, actual post-consumer/worker references and exclusion semantics. Only then arm the new route and durably ACK. Count any concurrent old-generation births explicitly; do not claim an empty queue from an old snapshot. New consumption after arming belongs to the existing sole controller, not a second launcher.

**Failure/rollback.** The pending C callback must catch `BaseException` across source load, preflight, apply and cleanup, contain even evidence-write errors, and return normally. Before any potential exposure, reverse B→E only if real absence of selected route claims/INTENTs is proven and their restore guards allow it. Once exposure is possible, first retain/install precise selected execution and admission HOLD guards; keep mandatory B/E routes and the staging fence. Best-effort restore optional IR view/adaptive/priority independently; a restore failure must not skip later containment. A cached primary/IR pending/decision must never reach the old entry after reader removal. Existing admitted unused or unresolved V3 claims prohibit automatic route removal; Main disposition is required. Scope/grants already durable remain and are reconciled, never refunded, silently retried or overwritten. No existing model is stopped or signaled.

This sequence preserves full physical RAM/forecast/canonical/claims/CPU/IO/native gates. It does not loosen CPU thresholds, activate V3 without the actual4 prerequisite, or authorize a recovery statistical union. Actual installer-source approval remains pending its independent review.
