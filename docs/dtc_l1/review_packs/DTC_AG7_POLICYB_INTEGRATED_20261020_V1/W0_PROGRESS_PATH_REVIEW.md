**Verdict: existing frozen ELF interfaces are insufficient for the AG7 protocol. A Framework-only new-ELF producer is source-feasible without changing c809 Core, but neither that new ELF nor a changed Core automatically inherits the original exact-source BASE eligibility. No equivalence or dispatch PASS is issued here.**

`update_stats():1553–1572` first moves local instructions to total, then resets local. A sample on the same simulation thread before/after that complete operation sees a coherent sum. A separate timer/signal handler reading the two fields is not equivalent: it can race the transfer and falsely double-count or regress. No audited wall-time bound exists on trace parsing, memcpy preparation or a whole simulated-cycle invocation. Consequently a phase label cannot mint a renewable lease. Silence beyond the frozen freshness bound must fail closed; no source-proven exception is established by this review.

## Minimal viable new producer path

It is **not necessary to edit Core merely to read completed instructions**: `gpu-sim.h:833–837` exposes the two counters publicly. The existing Framework `simulate():150–171` owns the single-thread cycle loop. An opt-in Framework observer can sample the coherent sum immediately after `cycle()` returns, before destructive queue consumption and outside counter-reset transfer. It can emit initial/phase and terminal records at existing Framework transitions, using a dedicated bounded nonblocking channel and monotonic time. It must omit optional CTA/natural-kernel claims unless their precise causal path is explicitly closed. A whole-run natural candidate needs all commands exhausted, kernels drained, no limit/deadlock/abort/STOP, strict full-input receipts and actual natural root exit0; later contradictory receipts must invalidate it.

That design can leave Core source and linked Core library bytes unchanged, while changing Framework source and **the accel-sim ELF**. It still needs actual exact postfork PID/start_ticks/generation binding, input/ROI/stream/epoch/sequence fields, channel failure behavior, immutable runtime closure, and W1/W2 qualification. The safe-point producer can fail closed if a single cycle or trace phase exceeds freshness; the review provides no guarantee that every real workload will meet that bound. There is no reason to create an unsynchronized background counter reader merely to hide such a failure.

Using smaller existing `-gpgpu_runtime_stat` values is not a free qualification: it changes the frozen tuple, synchronously writes all perf counters and can create substantial host I/O; it still lacks the required protocol/terminal provenance and no finite wall bound follows from cycle count. LD_PRELOAD, ptrace memory reads, external signal-triggered flushes or runtime patching are not pre-existing qualified progress interfaces and do not preserve the original loaded-image/runtime contract by assertion.

## Comparator decision required before any fork

The original BASE reuse decision explicitly scopes eligibility to original c809 Core **and exact executable/runtime/library/loader/cache/options/input/ROI** for AG6. Keeping `git diff` to observation code, or keeping Core source unchanged while replacing Framework ELF, is insufficient to transfer that decision. Independent BA review would need a real equivalence bridge: frozen old/new executable and linked-library identities, ABI/layout/loader binding, complete producer read/write dependency analysis, proof that new paths cannot modify modeled state/options/RNG/timing/ROI/trace, preservation of original execution ordering and flags, plus qualification of default-OFF behavior and failure/termination effects. Any injected library/runtime must be included. CPU policy tests alone do not demonstrate scientific model equivalence or fullsim completeness.

This source review establishes a minimal implementation direction and specific existing-interface failures; it does **not** establish that bridge. If BA cannot independently support a scoped comparator with the new ELF using sufficient non-simulator evidence, the smallest scientific remedy is explicit authorization for new same-build matched BASE measurements (GEMM and Gaussian) before treating four ON measurements as speedups. Those additional BASE starts are outside AG7's four authorized starts. Preserve AG7 0/4 until the comparator gate and all other gates pass; do not use an ON arm as a free canary or substitute incomplete perf rows for a BASE.
