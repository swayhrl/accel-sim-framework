# Independent memory-feature classification V1

Frozen before joining DH cycles. Scope: 23 original accepted complete four-configuration frozen trace identities; no identity/cell replacement. These are overlapping descriptive candidate labels, not proof of a runtime bottleneck, and no label is defined by speedup.

1. **L2_HIT_DOMINATED_REQUESTS**: accepted CH GLOBAL_ACC_R:HIT / CH accepted global read 32-byte sector requests >= 0.80, with at least 1,000 accepted reads. HIT_RESERVED is reported separately, not a ready hit. Denominator excludes reservation failures and the duplicate MSHR_HIT alias.
2. **DRAM_REQUEST_DOMINATED_READS**: issued CH DRAM read 32-byte atoms / accepted CH L2 global read 32-byte sectors >= 0.50 AND DRAM read atoms / active-thread instructions >= 0.001. This is a traffic-location classification, NOT a statement that DRAM time dominates. L2 denominator excludes local/texture/constant reads whereas DRAM includes all modeled read classes; any classification with non-global traffic is flagged domain-mixed.
3. **MAPPING_AMPLIFICATION_CANDIDATE**: qualified per-warp global-load distinct-128B-line-reference sum / global-load warp records >= 8, for a kernel contributing at least 25% of CH application cycles. **HIGH_REVISIT_OBSERVED_RANGE** separately requires scanned global-load line-event references / distinct 128B lines >= 4 in the stated bounded scan. Neither implies conflict misses; request duplication in the simulator cannot be derived from static address repetition.
4. **LOW_CTA_PARALLELISM**: a kernel contributing >= 50% CH cycles has fewer than 64 CTAs. SM count 64 is taken from the fixed modeled GPU; min(CTA,64)/64 is only the maximum simultaneously active SM fraction assuming one CTA is assigned to one SM, not achieved occupancy. CTA distribution across kernels must remain visible.
5. **ARITHMETIC_DENSE_TRACE**: arithmetic/logical/conversion warp records >= 35% of all qualified warp instruction records, AND global load+store warp records <= 20%. **SFU_DENSE_TRACE** separately requires MUFU root >= 1%. Arithmetic roots are explicit in the producer script; no source-level FLOP equivalence is claimed. Ratios count warp records (not active-thread operations); arithmetic and memory warp records may have different masks.
6. **INSUFFICIENT_FOR_ABOVE_LABELS**: no rule above passes or a required denominator is absent. Missing metrics are null, never zero. Unscanned unique lines/reuse distance/bursts are missing rather than inferred from program names.

Instruction denominators: traffic intensity uses complete qualified active-thread instruction count; opcode fractions use qualified warp instruction records. L1 lower request count is the original CH DTC_L1_lower_requests_acquired model-native request counter, not automatically a byte/sector count. L2 units are 32-byte sectors; DRAM units are 32-byte atoms; address features use distinct 128-byte lines. They are never counted as the same unit.

Address scanning: single sequential low-priority process, hard AS <= 1 GiB, total physical trace bytes <= 1 GiB, <= 15 minutes, <= 8 MiB/s cumulative reads. The copied qualified body parser's decoder is reused for modes 0/1/2, with schema assertions. Full-scan SHA is rechecked only when EOF was reached. A prefix scan records prefix SHA and prior whole-trace SHA separately. Per-warp reuse interval is the number of intervening global-load line events in serialized trace order, NOT LRU stack distance or cross-SM time. Across-warp aggregated repeats are not overlapping outstanding duplicate requests. Address span is scanned address max-min+width, not allocation size. Distinct tracking is bounded; overflow changes exactness to a lower bound. No timestamped burst proof or true reuse-distance claim will be fabricated.

Hash response is joined only after feature labels are frozen. DM/DH, CM/CH, CH/DH and CM/DM use original accepted cycles; no result-dependent relabeling or row deletion is allowed. Complete panel coverage is 23/42; labels do not cure input/capture certification gaps.
