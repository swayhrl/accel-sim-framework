## How to use this classification

- Mixed measured responses: investigate the actual local/downstream interaction with opposing cases; do not assume that increasing resources monotonically improves time.
- Local response with tested downstream zero: prioritize local lifecycle/admission/service hypotheses, while retaining the untested Oracle opportunity as UNKNOWN.
- Downstream response with local zero or UNKNOWN: the existing counterfactual direction is in the tested lower path, with common CH system gains reported separately; absence of a local measurement is not a local negative.
- Tested downstream zero and local UNKNOWN: retain the application and inspect source/kernel/dependency/initial-state evidence. There is no basis to label it compute-bound or without DTC headroom.

No class supplies a numeric upper bound, physical PPA result or permission for simulation. All32 remain in the audit; outside3 and unresolved7 stay outside. No per-program-best unified GM is formed.
