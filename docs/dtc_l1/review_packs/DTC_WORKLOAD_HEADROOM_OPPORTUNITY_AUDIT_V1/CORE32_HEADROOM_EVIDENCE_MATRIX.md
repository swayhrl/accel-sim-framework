## Hardware and measurement limits

CH active conventional L1 is96KiB/768Tags with PAPER_BASE PIB256. DH has an ordinary16KiB compatibility path and active OO512Tags/640 physical lines (nominal80KiB)/PIB128. These capacities cannot be summed into a single selected-load cache or used as equal-area proof. Physical expansion keeps512 searchableTags; PIB192 also enlarges lower-create queue bound128→192. Tag grant settings do not prove achieved per-cycle throughput. FR-FCFS F128/F256 also change shared partition credits. Printed cumulative counters, gauges, running peaks, request objects,32B sectors/atoms and conditional latency means have different meanings; missing is not zero. MRQ is request construction to bank assignment, not complete DRAM service latency.

Whole declared-trace replay is distinct from complete native application capture and numerical correctness. HtoD event order is not proof of changed values/read overlap/coherence. Zero measured DRAM reads or zero tested sensitivity is not proof of compute dominance. Static address repetition is not dynamic cache hits, pending-hit merges or critical-path time.
