## Remaining actual-source authority gap

For every selected trace, preserve the registered input/bundle SHA and header observations separately from each candidate source. To close actual capture authority requires retained original or prepared CU/header hashes, exact compiler/flags/macros, executable hash, capture command/ROI and trace-member identity linked to that executable. The source default dimensions and source defects cannot fill those missing links. Neither a historical zero-mismatch claim nor a build script's existence supplies the missing chain. The atlas records these gaps without modifying accepted results or frozen membership.
