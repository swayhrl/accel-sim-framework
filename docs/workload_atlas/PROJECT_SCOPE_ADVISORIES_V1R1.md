# Shared input-scope advisories — V1R1 (read-only scientific interpretation)

Historical accepted cycle counts, strict/trace identities and positive/negative results remain valid **within their already-accepted simulator/trace contracts**. These observations do not rewrite those contracts into full native application certificates. Full capture-source/ELF/ROI/original-input binding is unresolved.
