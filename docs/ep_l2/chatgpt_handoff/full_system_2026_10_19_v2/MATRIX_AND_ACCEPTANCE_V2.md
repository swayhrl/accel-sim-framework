# 最终完整方案的矩阵与验收

本文件与MASTER_FULL_SYSTEM_V2.md共同生效。以下是计划，不是已完成结果。使用清楚的中文名展示；机器ID只是运行器内部标签。

## 1. 固定最终设计，不挑每应用最好开关

S=传统静态写回暂存结构，最终同binary基线。
W=统一写回存储/原位转权这一项改进。
V=动态保留淘汰数据并真实服务复用。
R=经过认证的只读pending标签/请求跟踪优化，其内部T标签脱离、M避开传统line-MSHR可分别开关。
F=同一最终binary和固定政策的W+V+T+M完整方案；没有只读认证的line正常回退，V无复用时自然不命中。

不能将不同应用的W-only、V-only、R-only最好结果拼成F。不能把CLEAN_ONLY或没真正集成的开关当F。全功能正常时序均采用有限bank/目录端口，不带COPY_FREE/DATA_FREE参考。

同一输入组必须完整trace、同一可执行文件、同一非实验变量、同一终止条件。主图七输入首选原五种SAD/Vector/CFD/Conv/FWT和D已预登记btree/dwt2d。输入无实际可用性则D在看新speedup前说明替换或缺失；不把内核数、不同规模当新的独立workload。

D为每种输入产生只读覆盖率和保守回退原因。已有294912只读line的Conv证书只覆盖其冻结epoch，不能复制给其他六种应用。全无法认证的输入可以以R安全回退运行F，但必须标RO覆盖0，不把零触发写成收益证据。

## 3. 消融不是简单关一个总开关

### F−W最容易做错

它必须保留V/R可运行所需的公共映射、目录与事务身份，但将写回改回固定16项暂存、正确复制和真实复制/发送服务；其他两项规则保持。数据总预算仍1168，明确哪16槽承担静态写回责任，其他角色能用哪些槽，不能给V/R额外赠送空间。

若现架构上W与V/R不可独立切分，A不得删除公共分配器使V/R同时失效后把它叫F−W。提交DEPENDENT_CONTROL_UNSUPPORTED并保留W-only和S_COPY_FREE诊断作为有限解释，缺少F−W不得冒名用S替代。完整设计仍可以先验证，但三项独立贡献结论须服从能实现的对照。

F−V保留W、RO和同公共预算，不再保留可选victim；有必要保留直到写回接受的脏数据不是额外victim功能。F−R关闭T/M并回到普通只读pending规则，保留W/V。不支持原子时完整应用仍限非原子；定向负测试必须安全拒绝/回退，不能暗中扩大原子资格。

### 固定victim

固定容量、动态容量共用总数据和目录预算，读命中额外查找延迟与数据端口费用一致。固定大小根据既有预算与baseline压力预登记，不按F速度调到最差。报告静态保留区牺牲哪个其他角色的空间；不能解释为单纯增加总容量。

### COPY_FREE / DATA_FREE

沿用A已经完成的细分：COPY_FREE免除复制两阶段服务与约定的staging等待，但仍正确搬运版本/值，发送读取仍收费；DATA_FREE只免除L2数据bank争用，保留一周期复制锁存等固定流水、标签/请求/WAD容量、真实miss、显存和下游/响应背压。二者不是同一个ideal。F_DATA_FREE是新组合，必须新增生产路径资格；不能因为S/U单独诊断已测就认定全机制诊断合格。

仍有前端pending replacement串行、标签不足等就如实记残余等待。不把DATA_FREE宣称整个L2完全无阻塞，更不旁路L2或使所有请求命中。

## 4. 完整组合最小正确性

E独立使用真实cache/partition输入和独立数据参考，核：
- 同池resident、WB、clean/dirty victim、RO pending生命周期；mandatory已发事务返回落点不可被可选victim抢走。
- 共享WAD/TVD目录满/让位、索引或CAM不同操作预算；frontend之外WB接受/完成查找费用不能遗漏。
- victim读pin尚未释放时WB完成；晚到WB完成不会清理已复用的目录代号；旧packet快照不随槽位重用改变。
- RO标签已经指向新line，旧sector乱序返回只完成原请求；同地址多个只读事务不混身份。
- RO与victim同时处理同地址、写入/host更新使只读认证失效；正确回退而不是返回陈旧数据。
- 响应队列/下游满、descriptor/目录/槽满后解除限制能排空；有限端口和每操作记账一致。
- T-only、M-only、完整R分别真实触发，非法组合拒绝，默认全关保持对应基线。

不要重复未改动55/21/12所有fixture来源；合并去重后保留受影响共同回归和新交互测试。控制脚本82PASS不计入上面的native执行PASS。

## 5. 每机制的最少科学指标

W：不同受阻请求、首次等待到解除的分布、WB实体占用、真实复制和发送操作数、总周期。
V：实际可保留机会、真实命中、实际lower读字节减少、目录/数据服务额外开销、总周期。
R：标签/传统line-MSHR实际拒绝、有效独立在途与完成吞吐、重复同地址lower读和流量代价、只读证书覆盖、总周期。
F：以上交互和统一资源占用，主图逐应用结果/均值，退化/不触发不删。

重试次数不等于不同请求，跨bank/slice累积等待不等于独占程序stall。机会影子模型、定向合成测试、完整真实应用分别呈现。增加目录字段/访问、延迟和开关控制成本单列；旧WB-only R3面积与时序不能充当三机制完整方案PPA。
