## Fairness and optimization boundary

S, W-only and WV preserve 1168 physical slots per slice, 32x8 Tag geometry, P1 bank service, descriptor512, WAD128, line-MSHR128, queues, DRAM100 and clocks. S has static role allocation and WB copy; W-only has pooled FT2 and in-place WB. W-only is not a copy-only oracle. WV adds directory lookups, retention, actual victim service and dirty forwarding as one mechanism package. The unused physical roles in a smaller Tag organization are not automatically an area saving. Fixed physical capacity is not identical useful allocation reachability.

C1 service-aware optional reclaim remains a design hypothesis. No patch or new structure run was integrated. It must preserve mandatory/readers/pins/generation/bank colors and update directory-full preview and bank-compatible reclaim consistently; one nominal bit/entry does not prove free timing or PPA. Stencil victim service and Scan WAD/bank/retention competition justify decomposition before changing policy; neither proves C1 will accelerate an application.
