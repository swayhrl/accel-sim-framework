Actual entry arrival, split child, queue entry, first-head, admission and completion remain separate. MS head populations and FT tracked-requester populations cannot be divided without proven request-type and absorbed-path projection. Conv/Scan incidence rates stay withdrawn. V service/query/install populations differ. Per-reason waits overlap; do not sum as exclusive GPU stalls.

REF has MS/B0/M0a enabled and four heavy variables OFF: EPL2_DETACH_DIAG, EPL2_TAGPRESSURE_DIAG, EPL2_TAG_LIFETIME, EP_L2_EVENT_TIMELINE. EPL2_LIFE_WIRE=SUMMARY_STAGE does not enable full LIFE histograms. S runtime RO is NOT_APPLICABLE. FWT is WV_ZERO_RO, never substituted with RO-F.

Only build missing instrumentation if it changes a selected mechanism decision. Prefer a T-only bounded event hook before a general ingress/address collector. All new hooks default OFF; no extra probes, queue operations or scheduling decisions. Python dict/set reference code is not a low-overhead implementation. State <=16MiB, compact <=8MiB and host overhead <=5% are unmeasured targets, not PASS. Each enabled S/F/WV path needs its own relevant CPU and exact app OFF/ON controls; reference tests cannot transfer NI.
