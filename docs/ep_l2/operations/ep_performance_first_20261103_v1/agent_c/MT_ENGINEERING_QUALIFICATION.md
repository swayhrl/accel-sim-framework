## Immediate result

The existing RO Line-MSHR bypass switch is usable in the real production CPU path, both in Source78 and in the corrected-T 1e07 lineage. It enables a useful controlled M-decomposition family without changing RO protections. However a new scientific Host/parser/native mode still needs explicit qualification. CPU success is not application acceptance.

The first inexpensive branch is Source78 M0T1 versus its exact accepted M1T1/S/WV references, keeping legacy T behavior and all physical resources. Start with Vector6M if this family is later approved. The corrected-T branch uses one 1e07 ELF throughout and requires new same-ELF references. These branches must never be spliced into one performance comparison.

`ro_requested()` is `T || M` (`gpu-cache.h:904`). Setting both zero removes the RO runtime. It does not create an RO-enabled M/T-off control. M0T1 retains RO transactions and native Line-MSHR records; M1T1 uses the same shared descriptor pool while bypassing those native line records.
