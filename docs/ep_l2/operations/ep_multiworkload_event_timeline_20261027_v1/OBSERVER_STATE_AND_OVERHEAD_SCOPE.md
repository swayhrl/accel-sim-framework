# Minimal optimization design — UNEXECUTED

A later separately authorized passive implementation could eliminate unused-record initialization constants while retaining all visible semantics:

1. Keep the80B wire layout. Make event storage plain/uninitialized for unused ring/capture array slots; do not replace UNKNOWN by zero. Build every event through a helper that explicitly assigns all9 uint64 fields and tail fields, including each UNKNOWN sentinel, before it can become live. Metadata counters/head/count/used flags retain deterministic initialization.
2. Reset snapshot metadata only, replacing whole-array `s=snapshot()` assignment. On critical rank replacement, account discarded old events/full-trigger loss before resetting metadata. Never reuse old data outside the newly written prefix.
3. Preserve the ring live-count/head invariant, wrap order, exact prehistory copy range, trigger inclusion, postcapture length and censorship. Compressor/CRC may read only the established snapshot count; it must never inspect unused or padding bytes. No additional model probes/CAM/lookups, packet fields, maps, captures or policy changes.

Required future correctness checklist: compile/layout80B assertion; explicit initialization of every known/UNKNOWN field; zero/partial/full/wrapped rings; same-CORE R6→7→6 ordinal order; high64bit UID/parent/generation namespaces; unknown identity; first/high/full/actual-fail triggers; critical rank upgrade and replacement-loss accounting; prehistory overwrite/postcensor; truncated/error/overflow/CRC wire rejection; zlib bounds; all clock-domain combinations and regressions; summary/full LIFE behavior; S/F modes and repeated finish; deterministic OFF/ON semantic/cycle equivalence at an authorized matched point. A CPU uninitialized-read sanitizer/control should check that no unused slot reaches serialization. Actual build must compare readonly section sizes and requested observer object size, then separately measure RSS and same-boundary wall. The existing78f4 qualification cannot stand in for that future producer identity or its application results.

The design is not applied, compiled or run. Current78f4 Source/ELF, all accepted artifacts and ongoing Main simulations remain frozen.
