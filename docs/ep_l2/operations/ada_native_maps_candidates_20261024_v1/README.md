Parent review identified a second boundary: after the terminal stop is continued, the process can exit or become a zombie before RSS is read. Independent R3 candidates poll immediately after the mapping observation and use native_process_status_v1.py for the RSS read. An already-exited process skips the read; disappearance, missing VmRSS in a zombie, or exit after a read are normal only when poll confirms termination. A live unreadable process remains a failure.
