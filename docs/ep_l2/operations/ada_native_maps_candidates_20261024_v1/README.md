The new Core candidate preserves the prior complete64-bit PC path. WARPSYNC no longer aliases CTA barrier0. It explicitly waits until that warp has no older issued instruction and no pending store acknowledgments, then issues the original instruction through an ordinary ALU path. Buffered instructions are excluded from the older-issued count, and the invariant is asserted before the current buffer entry is removed. This is a conservative whole-warp serialization profile, not a hardware latency or overlap model. Zero-mask records allocate no synchronization effect. CPU probes cover buffered-versus-issued distinctions, older-instruction/store blocking, and the same-low32/different64 PC regression. Actual consumer ordering/request/termination acceptance still requires the separately authorized native attempt.

The new entry continuously samples the primary and observed descendants, saving PID, start ticks, monotonic time, changed maps, and the union of all observed file mappings. Every newly observed path is immediately checked against frozen file hashes. Two explicit SIGSTOP/SIGCONT host checkpoints occur after the first actual issue and after the simulation loop returns, permitting live primary mappings to be saved at both points. These deliberate host observation stops change wall time; simulated cycles do not advance while stopped. Sampling cannot prove that every transient DSO or short-lived child was observed.

## R3 terminal process exit race

Parent review identified a second boundary: after the terminal stop is continued, the process can exit or become a zombie before RSS is read. Independent R3 candidates poll immediately after the mapping observation and use native_process_status_v1.py for the RSS read. An already-exited process skips the read; disappearance, missing VmRSS in a zombie, or exit after a read are normal only when poll confirms termination. A live unreadable process remains a failure. Five direct CPU mocked exit/live positive scenarios and two live-unreadable negatives exercise these paths; no simulator application is used. The child-discovery scope is now explicit in the spec and eventual exit receipt: recursive main-thread /proc/PID/task/PID/children lists, not all TID children, orphans, or all transient descendants. V1 and R2 remain retained and unregistered.
