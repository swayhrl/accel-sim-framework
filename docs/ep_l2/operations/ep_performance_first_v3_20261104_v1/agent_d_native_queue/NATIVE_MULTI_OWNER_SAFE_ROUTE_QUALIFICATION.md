## Bounded candidate contract

1. Exact reviewed base bytes, or one exact reviewed grammar rendered from the pinned finite foreign authorization.
2. Every original EP route and all old bytes unchanged and in the same order. It never treats arbitrary insert-only changes as safe.
3. A narrowly fixed handler path, literal finite foreign identifiers and no wildcard, shell metacharacter, duplicate, EP namespace or extra command. No arbitrary shell AST is claimed safe.
