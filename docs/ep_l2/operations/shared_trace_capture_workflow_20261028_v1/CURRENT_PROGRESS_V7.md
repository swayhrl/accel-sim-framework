## 更新后的必要流程

1. 先绑定精确binary、argv、已有input、producer及真实采集闭合证据，并通过有界header检查尽早分流profile。
2. 较小且受支持的资产复用必要POST和分组；已有合格结果不重做。只对研究真正需要或新增关键特征做少量完整CTA的轻量模拟器检查。
3. 超大多流例外保存原始trace和必要依赖，用实际sender全SHA与关闭重开receiver全SHA形成RAW归档。原始文件没有SHA时不能编造expectedSHA；原始归档不冒充全记录或模型验收。
4. 常规与裁剪或RAW缺口分别公开。裁剪按实际有效比例记录，不默认每个输入都能得到2.5%；每kernel仅一个CTA时保留一份即100%，必须如实说明。
