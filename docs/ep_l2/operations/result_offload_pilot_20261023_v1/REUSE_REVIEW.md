V9's published35-case receipt and industrial16-case compression receipt demonstrate their frozen scopes only. First authorized tiny synthetic work should use uncompressed V9 primitives, keeping the low-volume path simple; compression generalization is optional after that. A new parameterized EP/DTC adapter would need a fresh selector/schema/destination scope, orthogonal receipt state binding, exact policy injection and scoped qualification. It must not introduce a permanent receiver, a scientific scheduler, watchdog or raw-log watcher.

Full DTC results currently contain a `perf_counter.csv.gz` symlink. V9 refuses symlink/hardlink scope by default. A future real selector must explicitly inventory and preserve relative symlink metadata under a newly reviewed policy, or clearly define a regular-file subset with the symbolic reference separately documented. Silently dereferencing/omitting it while claiming a full directory restore is invalid. EP parser-recovery subtrees can also reference original `raw.log` by symlink; retain those dependencies.

This phase supplies a pinned reference index and integration contract, not newly qualified transfer code. No old schema/allowlist, controller, receiver or scientific budget was edited.
