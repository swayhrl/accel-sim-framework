# 主图统计影响与替代决策边界

当前固定目标仍七输入：SAD、Vector、CFD、Conv、FWT、Btree、DWT2D。保留原32条件计划及40次累计实际启动上限；已有启动/失败不清零，D本轮新增0。Btree的S/F两项保持计划中的HOLD，不能用别的程序、另一规模或同应用多kernel伪装补齐。

E没有正式接受替代登记前，主图保留Btree缺项。完整七对几何均值保持UNKNOWN；不得把HOLD当0周期、0收益或1倍，也不把分母从7改成6。即使未来其他六对齐全，也只能报告6/7覆盖及明确缺口；另报六输入子集均值需要独立明确范围/审批，不能叫七输入共同主图。

D新增INPUT_APPLICABILITY.json只控制自身分析显示，不修改E ledger。它优先于可能残留的接受配对显示，阻止Btree旧pair/旧oracle重新进入图。analysis_preview/保留原七位置、标Btree输入HOLD；旧V2主图模板与历史发布保持。

E如在看替代应用新S/F结果之前批准一个有完整输入证明的候选，应发布新的登记revision：准确替代理由和时间、来源/规模/全commandlist/body/source语义、非原子/只读资格及同最终binary配置、替代关系与新比较ID。D随后按E实际映射改一个输入行；原Btree及原矩阵在历史中保留。同campaign继续扣除40，补跑/失败也计入，不取得额外额度。

选择优先级是输入合法性和原先第一备选SpMV，其后仅按完整性、传统结构压力、可复现输入/成本与独立验证价值审查现有Scan/SGEMM；不读新方案加速后选最佳输入。D的建议不是正式变更登记或运行授权。

所有S/F结果仍必须E正式接受、同最终binary/固定完整策略/同输入和非研究变量。控制测试、静态语法检查、旧C7e终止及RO覆盖都不能直接填论文性能。EN-v18母稿不修改。
