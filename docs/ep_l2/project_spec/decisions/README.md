# EP-L2 Architecture / Research Decision Records

Use ADRs for decisions that should survive individual Codex windows and experimental rounds.

Current records:

- `ADR-001-l2-structural-objective.md` — a better L2 is defined first by structural/service effectiveness under comparable L2 budget/timing; system speedup is a stronger separate evidence tier.
- `ADR-002-bottleneck-substitution-evidence.md` — bottleneck substitution is first-class architecture evidence but not automatically a performance claim.
- `ADR-003-performance-headroom.md` — downstream headroom is a controlled sensitivity study, not a primary-baseline rewrite.

New ADRs should use:

```text
Context
Decision
Alternatives
Evidence
Consequences
```

and should be added when baseline selection or a future EP-L2 mechanism becomes a reviewed design decision.
