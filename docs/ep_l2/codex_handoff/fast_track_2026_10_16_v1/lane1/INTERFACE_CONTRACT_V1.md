## Identity and ownership

`src/gpgpu-sim/ep-l2-ft-interface.h` publishes `ep_l2::PayloadHandle`
`{unsigned payload_id, unsigned generation}`. Existing
`ep_l2_payload_store::payload_handle` is its alias. `valid()` only means the
sentinel is absent; consumers must additionally check `handle_live()`.
ID/generation, not address, identifies an independent transaction. Physical ID
width is 11 bits for 1152/1160/1168 entries; software unsigned is not area.
Generation must not wrap across a live reference; first implementation rejects
wrap. The primary owner roles are published in `ep_l2::PayloadRole`.
A slot has exactly one primary role; pins, pending sectors, and read references
are subordinate state, never extra payload capacity.

## Allocator and transaction boundary

Lane 1 owns the sole `ep_l2_payload_store`; lanes 2/3 must not create a second
allocator or descriptor store. Existing handle validation and payload RAM
`request(handle, write, cycle, sequence, operation_class)` remain the service
entry points. Existing `mshr_table` remains the 512-descriptor authority.

The functional replacement API will use `ep_l2::Reservation` with victim,
staging and landing handles, tag_index, refusal and valid. `preview` is const:
it must not modify tags, WAD, payloads, generation, credits or replacement age.
`reserve` acquires all required resources before destructive tag mutation;
`commit` binds the actual packet/transaction; `rollback` restores all ownership
and credits, leaving no partial victim modification. An invalid token cannot
be committed. Lane 1 will publish source bindings as methods become executable.

`pin(handle)` / `unpin(handle)` preserve data until the last reader/descriptor
commit and pending sector return. `mark_sector_ready(handle, mask)` accepts
only a subset of the outstanding four-sector mask. Normal fills additionally
check tag attachment/generation; detached RO fills never install a tag.

## WB hooks and data placement

Production dirty-victim admission is `l2_cache::access` before
`data_cache::access` mutates tags. Bind every actual L2_WRBK_ACC generated by
all read/write allocation paths, not just one handler.

Static B16/B8: reserve WAD + finite staging + needed issue capacity atomically;
charge resident source read, staging write, and staging lower-send read against
the same 4-bank arbiter. A source must remain valid until its readout is done.
U_WB: transfer old handle to WB_STAGED in place; obtain a different landing
with the selected tag bank class. Do not retain a C-entry WB control cap.
WAD (128) and finite lower issue queue bound packet/control demand.

`wb_lower_accept(packet, cycle)` is called only after the real memport push
(L2interface -> L2-to-DRAM FIFO). It releases staging only after explicitly
accounted lower packet data ownership exists. Lower FIFO/DRAM queues carry
packet data and their configured capacities are recorded in the port ledger.
`wb_set_done(address, cycle)` retires the independent WAD/order obligation.
TVD may extend payload retention after lower-accept; that is a new TVD role,
not WBUF staging. With TVD OFF, accepted WB staging is released.

## Consumer integration hooks

Lane 2 TVD: tag-miss lookup costs one extra cycle and shares bank arbitration.
Read hit requires all requested sectors ready. WB_PENDING/INFLIGHT are not
reclaimable; write/atomic waits for true WB completion. Promotion transfers the
same handle atomically from directory to resident visibility. Dirty forwarding
must precede generic WAD-read denial. No new data array is allowed.

Lane 3 RO: full-epoch/line-certified requests only; reject synthetic write-
allocate reads, aliases, writes/atomics and unproved external concurrency.
Each accepted lower transaction reserves a landing and descriptor chain.
Attach/detach is by {id,generation}; no address-based cleanup of other detached
instances. Response commit releases the descriptor only after L2-to-ICNT push;
release a detached payload only after all fills and data readers retire.

Lane 4 ideal modes: default OFF, explicit vector, preserve ordinary API when
OFF; resource relaxation is diagnostic and cannot fill B16/U_WB results.

## Config/modes and progress

Planned `-gpgpu_ep_l2_ft_mode`: 0 OLD_D512_STATIC, 1 static finite WBUF,
2 unified WB; planned `-gpgpu_ep_l2_wbuf_entries`: 0/8/16 (default 0).
Mode 0 requires C=0; modes 1/2 require C=8/16 and banked payload mode.
Budget=1152+C, four banks, one line-sized arbitrary op/bank/cycle.
Primary C=16; C=8 sensitivity. Illegal combinations fail before running.
RO/TVD/adaptive bits remain OFF until independently validated integration.

WB drain must never depend on new resident allocation. Pool/WAD/lower full,
same-bank copy, pending sector and response backpressure require production
path reference-data tests. Updates to this contract will carry a new revision
and explicit source SHA; consumers must bind the version they actually used.

## Executable bindings — candidate revision 2026-10-16

Shared identity ABI remains V1. The Lane 1 implementation now provides:
`preview_free(role, bank)`, `reserve(id, role, owner, state)`, `release(handle)`,
`transfer(handle, role, state)`, `pin/unpin(handle)`,
`mark_sector_ready(handle, mask)`, `inspect(handle)` and `handle_live(handle)`.
The selected allocator is still the sole ep_l2_payload_store, never a second pool.
`ft_access` owns the serialized replacement reservation and commit;
`ft_rollback` unwinds it. `descriptor_admitted/lower_read_enqueued` bind actual
MSHR producers; `lower_ready/lower_accepted` bind actual memport handoff.
`ft_response_ready` charges the shared bank service before response enqueue;
`commit_next_access` releases read pins after the queue accepted the response.
WB completion remains ep_l2_wad_complete called by real set_done.

These executable bindings are candidates under production regression, not a
qualified performance release. The stage receipt supplies the exact source.
TVD/RO role extensions must be integrated by Lane 1 against this same store;
no consumer should duplicate WAD ownership or an independent payload allocator.
