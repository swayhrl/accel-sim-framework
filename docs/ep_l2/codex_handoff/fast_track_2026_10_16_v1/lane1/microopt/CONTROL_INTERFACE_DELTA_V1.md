One lower push per native cache-cycle invocation; blocked head bank ownership/sequence/generation is retained, and when it becomes ready it wins immediately.

A queue list is not a free hardware second read. No extra payload buffer or bank port. The one-bit decode proof must be carried through existing request/sector descriptors; it is not inferred from CACHE_ALL alone.

RG1 retains pending/selected ownership and age. Native response/fill/lower-WB/frontend heads plus copy phase provide bounded live ready wires. No additional Tag probe, payload read or speculative future-ready oracle is used. Response checks actual response FIFO credit; fill checks actual ReturnQ head/hold/waiting-for-fill; lower checks original MissQ head and actual lower credit; frontend checks its current head, phase and H0 immediate-ACK credit. Unknown readiness is conservative READY, never 'not called yet'. An unconsumed selected identity moves back only when explicitly unready or when an older ready identity resumes before consumption. Consumed service is never refunded; P1 is asserted even after same-cycle ready changes. No extra pipeline stage or hidden RAM service is modeled; timing closure of the ready/compare/mux path remains an RTL integration obligation.
