# Full-epoch RO input contract

The first oracle epoch is the entire kernelslist/commandlist, not one load or one isolated warp. All listed kernels and traced threads participate in the same canonical global-VA line domain. A 128-byte line qualifies only when global demand reads occur and no byte of that line has an epoch store or atomic, including accesses crossing a line boundary. Entire-input kernel hashes and ordered commandlist hash are bound. Threadblock/warp/instruction completeness and identities are checked; unresolved global/generic/local address mappings or unknown memory opcodes reject all candidate lines in that epoch.

This is explicitly TRACE_MODEL_CLOSED_WORLD, an experimental scope assumption: no CPU/DMA/external agent writes during the epoch, no virtual aliasing to different canonical VAs, no MMIO, all prior writes/writebacks drained at activation, and copy commands at drained boundaries. These properties are not claimed to be proven about real GPUs by SASS traces. A production launcher that cannot enforce them must reject the certificate and use the ordinary path. Whole-application classification is deliberately conservative about cross-kernel/stream overlap. Shared-space instructions cannot write a global line; unresolved local/generic mapping is not silently treated as a distinct safe address domain. Synthetic write-allocate reads, atomics, writebacks and unknown request classes cannot enter RO even if a line appears in the certificate.

SQLite stores per-line read/store/atomic sets with a 16 MiB page-cache cap and file-backed temporaries. No all-trace in-memory dictionary is built. coverage.csv/exclusion.csv report exact lane-reference and unique-line denominators. certified_ranges.csv is a compact same-line membership input, not a reuse prediction. oracle.sqlite3 and the explicit line list remain at the result root. All artifact hashes are in manifest.json; --verify rechecks every original trace and artifact. The producer is frozen and its exact script bytes are checked against the declared Git SHA before preprocessing.

Offline oracle processing and a runtime ideal annotation are experimental costs; no compiler classifier or free hardware membership RAM is claimed. RO eligibility never uses future reuse information. Any unproved concurrency/address scope is ordinary-path fallback.
