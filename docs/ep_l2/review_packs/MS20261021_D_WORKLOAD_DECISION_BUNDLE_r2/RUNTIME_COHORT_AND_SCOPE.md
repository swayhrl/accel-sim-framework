## Three different evidentiary scopes

1. **Frozen-trace model replay.** Preserve exact commandlist/body composite, whole input, native grammar/atomic scope, runtime/source/profile/config binding, closed-world canonical-VA assumptions, model data/version lifecycle and E terminal/independent acceptance. FWT exact main61 Q1d3af457 remains independently qualified with18 PASS gates per E's current review. This bundle reads that existing metadata and does not re-qualify it. Current physical content and durable execution/resource preflight remain E's original future-use gates.
2. **From-source recapture.** Original scaled source/patch, capture executable, compiler flags, actual toolchain/GPU/tracer identities may be missing. A pinned public reference is not capture-source identity. These facts limit reproducible recapture; they do not automatically invalidate an already qualified frozen-trace model.
3. **Numerical application reproduction.** Original initialized values/generator, dimensions, outputs/reference comparison and exact application implementation are required to support numerical-output claims. Trace addresses or symbolic sector versions do not prove SASS numerical correctness. Missing numerical facts remain explicit; no universal numerical gate is added to existing trace-model qualification and no new numerical claim is waived through.

FWT's existing genuine zero-covered-line model is preserved and supplies a RO-negative background; SGEMM low historical W pressure is an independent contrast. No new B assignment is justified by the currently available evidence.

Neutral order remains FWT original restoration, SGEMM independent dense/low-pressure control, BFS conditional irregular/host-updated input, Hotspot single-kernel reserve. No application-count target and no unknown or observed F acceleration is used to change this order.
