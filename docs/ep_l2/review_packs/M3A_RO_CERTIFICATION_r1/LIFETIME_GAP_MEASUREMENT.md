# Decision-critical lifetime gap

M0b emits allocation→first-fill and allocation→all-ready but not allocation→final retirement, all-ready→final retirement, or last-lower-issue→final retirement. Candidate B therefore requires a default-OFF, epoch-safe final descriptor/Line-MSHR retirement callback before a functional decision. No telemetry was added here because safe final identity/ownership must first be reviewed; unsupported intervals remain `UNKNOWN_NEEDS_MEASUREMENT`.
