# Figure 2 blocker-composition draft

This new, figure-only draft redraws the five WBUF=8 blocker classes as a 100%-normalized composition **among blocked cycles only**. Every nonzero stacked bar therefore sums to 100%; it intentionally has a different denominator from the Figure 2 blocking-rate figure.

Input is the frozen `PAPER_FIGURES_DRAFT_v3/plotting_tables/FIG2_L2_STRUCTURAL_BLOCKING_PAPER_DRAFT.csv`. The exact per-workload numerator values and resulting fractions are exported in `plotting_tables/FIG2_L2_BLOCKER_COMPOSITION_100PCT_PAPER_DRAFT.csv`.

No simulator workload was rerun and no raw log, scientific value, provenance, parser, or existing figure pack was modified.
