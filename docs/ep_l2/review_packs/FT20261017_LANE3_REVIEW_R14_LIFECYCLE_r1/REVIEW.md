## Confirmed source defect F1: a native requester could borrow RO ownership

Reviewed prior RO Core5ae8b06d58b61189140f571ab37b5f6d51228632. With tag_detach=ON and line_mshr_bypass=OFF, admit a certified GLOBAL_ACC_R for line A/sector0, then actually lower-accept its sector. The RO transaction owns the native line index and sets its issued mask. A TEXTURE_ACC_R to the same sector is deliberately not an oracle candidate. Prior ft_access therefore falls through to data_cache/baseline_cache::send_read_request. The existing native entry passes mshr_table::full_reason; needs_lower_read is false because RO issued that sector. mshr_table::add allocates a native descriptor and descriptor_admitted pins the same payload, without another lower packet.

RO fill calls transactions::fill -> mshr_table::ro_line_ready, which updates masks but does not queue native descriptor responses. Only native mark_ready scans native descriptor_ids into m_current_descriptor_response. No native return is owed by the coalesced request, so a finite execution ending at this sequence cannot drain its descriptor/pin. RO retirement does not solve this: release_ro_line keeps the native list, without queueing it. This is a concrete source counterexample; no hang or runtime failure is claimed to have been observed this revision.

There is also a related unsafe bypass-ON boundary: an ordinary native sector miss can try to borrow an attached RO landing, while native lower_read_enqueued requires a RESIDENT owner. The repair excludes mixed native/RO ownership instead of adding another response path, allocator, address CAM or descriptor pool.

## Local repair and exact scope

Eligible original reads still use the frozen oracle-backed merge path. A noncandidate request finding an active RO owner retries before Tag, descriptor, pin, queue or allocator mutation; preview reports the same refusal. After RO retirement it can retry through the normal native path. With bypass ON and a detached completion there is intentionally no address-wide transaction search: a distinct normal landing can exist, and the old detached payload remains independently pinned.
