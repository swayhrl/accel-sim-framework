# Qualification scope and consumption gates

This package delivers new production routing, not application performance. Producer-directed tests exercise actual l2_cache and memory_sub_partition hooks. Lane 5 independent qualification is pending for this exact new Core/binary; prior module qualification is not inherited.

The isolated acceptance build freezes Core and Framework source before compiling. Binaries, command/config/fixture digests and raw log hashes are in BUILD_AND_TEST_IDENTITY.json and directed/SUMMARY.json. Bootstrap builds and engineering failures are excluded; they were never promoted as acceptance evidence. Full raw build logs stay in Lane 3's results directory and are hash-indexed.

The l2_cache fixture covers all four switch combinations, same-address independent handles versus retained native MSHR merge, reversed sector returns, reuse-aware Tag protection, actual bank refusal, ICNT-style response delay, mixed native128+RO384 D512 exhaustion, original GLOBAL_ACC_R classification, certified writer rejection, dirty-victim WB/WAD/version retention, foreign native-response pin protection and full epoch activation/drain boundaries. The partition fixture additionally traverses actual frontend, memport, DRAM model, ReturnQ and one-entry ICNT FIFO with a held consumer and exact-once requester tokens. Symbolic sector-reference validation has the same dataless-SASS limits as R0; it is not a numerical application output proof.

Malformed range hash, manifest hash, scope, shortened epoch and wrong commandlist must be rejected. Five Python config-binding tests check immutable output, empty certificates and scope/identity failures. R0's eight production directed groups run with both RO switches OFF; historical full-application all-OFF pairs are reused, not rerun here.

Runtime denominator: `accepted_global_reads` counts original GLOBAL_ACC_R requests accepted at L2; `accepted_oracle_candidates` counts those whose 128B line is certified, including ordinary hits/fallbacks; `accepted_ro` counts requests actually routed through RO transactions. Retries are excluded. Input denominator: the frozen whole-commandlist oracle reports traced global-read lane references and certified candidate lane references. Those are different populations and cannot be converted into each other or called L2-miss coverage. The synthetic fixture's counts must never fill a workload performance row.

`lower_sectors` is accepted RO lower sector traffic. `concurrent_duplicate_sectors` compares simultaneously live same-line issues; it is not total application amplification or DRAM savings. Any future amplification/saved-bytes claim requires matched OFF/ON lower/DRAM traffic over the same full application. RO bank counts are separate from resident operations.

Lane 1 should apply CORE_MINIMAL.patch and the Framework hook to a new R3 integration tree derived from exact R0 (or explicitly resolve against its diagnostic R1). Keep R0 binaries/configs/runs untouched. CORE_DIRECTED.patch provides the test harness. Independently test both bits, required combinations, and launch/termination identities before marking a release qualified. Formal runs remain Lane 5's allocation. The frozen five real workload inputs are not newly run in this package; their application runtime qualification/performance remains NOT_RUN.

Legacy C7/M0a preview `needs_new_mshr` flags remain logical admission-credit requirements in the RO path; they are not a count of physically allocated native entries under bypass. Actual native occupancy comes from the existing table and is asserted by the bypass fixtures. Do not use those preview flags as physical RO Line-MSHR allocation statistics.
