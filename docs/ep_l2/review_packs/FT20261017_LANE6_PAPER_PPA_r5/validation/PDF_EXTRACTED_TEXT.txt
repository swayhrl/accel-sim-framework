                   V. Related Work and Scope
    Flexible storage organization. V-Way increases tag capac-
ity relative to data and uses indirection for demand-based
associativity [1]. Tag-Split Cache instead changes data-storage
granularity while retaining coarse request granularity [7]. EP-
L2 fixes resident tags and line/sector sizes, targeting cross-role
payload lifetimes rather than either form of spatial packing.
    Storage reused for transient state. In-cache MSHR designs
reuse cache storage for pending-load information, subject to
placement and port constraints [3]. MiCache shares FPGA
storage between cache lines and MSHR subentries, converting
MSHR entries to cache entries on response [4]. EP-L2 instead
retains existing dirty data during resident-to-WB transition,
with request metadata and WAD separately bounded.
    Other resource and access policies. Gebhart et al. repar-
tition SM-local registers/cache/scratchpad storage at kernel
boundaries; their evaluated cache is write-through [2]. DL-
