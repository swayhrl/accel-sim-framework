# Baseline-decision evidence — recommendation only

Recommend **D512 / L1 BASE / Line-MSHR128** as the calibrated research
baseline, subject to independent ChatGPT decision; this is not a code/default
change.

- D512 removes the D256 descriptor structural ceiling across the promoted
  breadth and exposes Line-MSHR/per-address/lower/scheduler pressure.
- Added descriptor metadata is 2–4 KiB/slice, 128–256 KiB/chip, or 1.39–2.78%
  of the frozen payload-byte budget: plausibility context, not area/performance.
- Cycle response is generally small, so relief is bottleneck substitution, not
  an asserted latency/throughput improvement.
- Promoted L1 META-HR/BANK-HR has no broad >5% material response; btree remains
  a small local control. Line-MSHR stays 128 because Lane-E finds its D512
  exact-full relief downstream-limited.

This explicitly rejects: **choose D512 because it makes MSHR the bottleneck.**
D512 is recommended because it removes a bounded-cost metadata throttle while
preserving the visible causal resource chain.
