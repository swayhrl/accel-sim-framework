# Research documentation index

This directory separates the three simulator research tracks from shared
reference material.  Plans are working contracts and observations; only the
corresponding qualified run directories and result tables support performance
claims.

| Area | Contents |
|---|---|
| [Decoupled-L2](decoupled-l2/README.md) | L2 design history, FRC/LateBind plans, handoffs, and the FRC reference paper. |
| [TLS-Cache](tls-cache/README.md) | TLS reproduction plans, evidence ledger, resource planning, and source paper. |
| [C2P-Cache](c2p-cache/README.md) | C2P source paper and local figure/result provenance. |
| [`reference/`](reference/) | Cross-project dissertation and presentation reference material. |
| [`operations/`](operations/) | Repository workflow and skill-deployment notes. |
| [`presentation/`](presentation/) | Presentation-outline planning notes. |

The long-running Decoupled-L2 experiment records that are actively consumed by
runners remain at the `docs/` top level with their existing stable names (for
example `decoupled_l2_runs.md` and `decoupled_l2_workload_memory_plan.md`).
