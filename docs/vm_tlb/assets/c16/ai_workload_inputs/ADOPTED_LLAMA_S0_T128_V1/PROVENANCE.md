# Adopted Llama S0/T128 input authority V1

This directory is a **new future-use adopted input authority**, assembled in
V2C from three byte-exact payloads recovered by V2A.  It is not a historical
five-file bundle recovery.

The immutable historical conclusion remains
`HISTORICAL_FROZEN_INPUT_NOT_RECOVERED`: the missing
`LLAMA_S0_TEXT_BINDING_RECEIPT.json` and
`C16_FIND_AND_TRANSFER_LLAMA_S5_FROZEN_INPUT_BINDING_RECEIPT.json` were not
recreated, renamed, replaced, or claimed to be recovered.

The original source paths, source SHA256 values, Git-copy SHA256 values,
semantic identity, and V2A source commit are recorded in
`ADOPTED_INPUT_RECEIPT.json`.  The three payloads retain their original names;
in particular, `frozen_token_ids.json` was not renamed to a historical
filename.  This authority is future-use-only and makes no retroactive change to
RTX3090 authority or RTX4080 R5 evidence.
