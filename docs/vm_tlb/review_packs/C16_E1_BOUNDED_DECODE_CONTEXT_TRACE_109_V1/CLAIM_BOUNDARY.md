Runtime qweight CUDA virtual addresses directly match NVBit trace-native numeric addresses for real-artifact canaries at layers 0, 14 and 27.

The strongest address claim is:

`TRACE_SIDE_VALIDATED_SIM_L2_MAPPING_PENDING_174`

No claim is made that GPGPU-Sim L2 already preserves this namespace. No Accel-Sim or GPGPU-Sim run, mutation, oracle mechanism, classifier, or mechanism experiment is included.

The full tensor byte SHA values under NVBit vary relative to the earlier native timing authority while model/config/token identity, generated tokens and the complete kernel function/geometry path remain fixed. Those tensor SHA values are retained only as telemetry and are not used as formal selector identity.
