# R21A first timing gate — frozen before any Dready formal sample

Discovery input: exact `sitraj.xyz` frame55, 64 Si nodes, 1394 directed periodic edges. A0 uses the unchanged natural graph, official `enable_OpenEquivariance` atomic `deterministic=False` AOTInductor/ASE package. Dready uses the source-backed once-sorted graph with one shared sender transpose permutation and two `TensorProductConv(... deterministic=True ...)` consumers, compiled with the same NequIP source, Torch/OEQ environment, `--mode aotinductor --target ase --device cuda --no-tf32`, dynamic bounds and frozen discovery-shaped `--data-path` method. Both packages were already compiled and five-run numerical qualification passed at `atol=rtol=5e-5` for energy and forces.

The arm-specific required graph representation is already resident on the RTX4080 before each timer. This is an intentionally idealized free-readiness comparison, not deployment performance. Neighbor search and deterministic graph preparation are outside this first timer. Compilation/JIT is warmed outside formal samples. The timed wall/CUDA-event interval encloses one complete compiled model call through synchronized energy+force commit; both official ASE AOT targets may also return other model fields, identically specified. No label, output reuse, training graph or host neighbor search is in the timed interval.

Three paired groups alternate A0→Dready / Dready→A0 / A0→Dready. Each arm/group has two warmups and five formal samples. Save every formal output and wall/CUDA-event sample; check every formal energy/force against the frozen five-run e3nn reference mean and graph identity with the unchanged `5e-5` contract. Group metric is median full-call wall time; noise is ordinary unscaled MAD of five samples, taking the larger arm. Dready MATERIAL requires all three group medians faster, median relative improvement ≥5%, and each group gap >3× larger-arm MAD. Stable submaterial closes as `R21A_READY_HEADROOM_NOT_MATERIAL`; mixed/noisy is `R21A_RESULT_MIXED_NEEDS_REVIEW`. Only MATERIAL authorizes Donline.
