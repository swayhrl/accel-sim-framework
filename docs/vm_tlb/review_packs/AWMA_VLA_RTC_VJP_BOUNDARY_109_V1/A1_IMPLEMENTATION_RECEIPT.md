# Actual strong-software A1 implementation

The preregistered author-supported `torch.compile` (`max-autotune`) canary did **not** qualify: its first real guided-VJP execution terminated with `torch._dynamo.exc.InternalTorchDynamoError` wrapping CUDA `misaligned address`. No compiled action output or timing was accepted. We did not try another compiler mode, Torch version, backend, model, denoise count, or algorithm. Full compiler stderr is indexed as raw.

The sole formal A1 was therefore the preregistered fixed-shape reuse fallback in `util/vm_tlb/awma/vla_rtc_vjp_boundary/a1_static_buffer.py`. It keeps the repaired RTC function and all denoiser/VJP arithmetic unchanged. One persistent `(1,50,32)` FP32 GPU previous-prefix buffer is zeroed once per complete guided chunk and receives the same prior reference-generated 10×7 normalized action tail. The original RTC code sees a full-size tensor and skips its ten repeated CPU-zero → GPU copies/padding. One fixed LINEAR `(delay=4, execution_horizon=10, chunk=50)` prefix-weight tensor is generated using the original function and retained on GPU; the RTC `.to(x.device)` becomes a no-op. Buffer and weight initialization (4.52 ms in this run) is separate from steady-state timing; the per-chunk zero/copy remains inside the observation-ready→commit interval.

Gate: all four discovery windows' raw and committed FP32 actions matched A0 exactly (max absolute and relative error 0); 240 tensor trajectory comparisons across the three guided windows also matched exactly. A1 retained 30 actual VJP calls, 30 action-output and 30 action-expert q_proj backward hooks, frozen weights, and zero parameter gradients. No guidance, steps, source coefficients, model, input, noise, dtype, processor, or delay changed.

Timing: the 45 formal guided A0 samples had median 231.912634 ms (MAD 0.343504 ms); A1 had median 232.688743 ms (MAD 0.295641 ms). Paired median A1−A0 was +0.770976 ms; no material speedup was observed. The first unguided chunk, which does not use the A1 RTC buffer, also shifted +0.643401 ms paired median across sequential acquisition, so a sub-1% slowdown should not be given a causal interpretation. All individual samples and paired statistics are preserved in `A0_TIMING.tsv`, `A1_TIMING.tsv`, and `PAIRED_TIMING_ANALYSIS.json`.
