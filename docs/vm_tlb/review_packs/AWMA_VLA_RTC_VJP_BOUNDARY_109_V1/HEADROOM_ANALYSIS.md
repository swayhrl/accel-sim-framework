# F3 headroom decision — before A1

This analysis was frozen after A0 and before any A1 GPU execution. It retains mandatory denoiser/VJP arithmetic, true data dependencies, and the existing visual-language prefix cache. The user-facing metric is complete observation-ready → committed action-chunk time, not summed kernel durations.

Episode A, four preregistered windows, B=1, delay=4 frames: 3 groups × (2 warmups + 5 formal), yielding 60 formal complete-chunk samples. The pooled median was **231.697893 ms** (MAD **0.526070 ms**); the 45 guided chunk samples had median **231.912634 ms** (MAD **0.343504 ms**). The first unguided chunk is retained as part of the four-window reference, not used as a no-guidance hardware bound. All formal outputs matched the frozen reference exactly (`max_abs=0`).

One separately instrumented guided window gave approximately 24.23 ms image/language prefix embedding, 8.59 ms prefix VLM forward, 91.30 ms across 10 denoiser calls, 98.88 ms across 10 `autograd.grad` VJPs, and 193.26 ms across 10 enclosing RTC steps. These CUDA-event intervals are nested and diagnostic; they are not added to the uninstrumented whole-chunk latency or treated as disjoint kernel durations. The enclosing RTC-step remainder after subtracting denoiser and VJP event durations was ~3.07 ms (1.32% of the guided A0 median). That small remainder is **not** an upper bound on all target state/lifetime overhead, because activation saving/reloading can occur inside the denoiser/VJP intervals.

Autograd saved-tensor hooks on each guided window reported 2,551,788,400 cumulative raw logical bytes and 2,499,627,900 per-step storage-deduplicated logical bytes over 10 VJPs; the separately observed peak allocator increment was 65,785,344 bytes above the loaded model baseline. These represent logical autograd state and allocator residency, **not DRAM traffic**. They do not tell how much of the 98.88 ms VJP interval is mandatory math versus removable materialization/transfer. No numerical VJP-state-only complete-chunk ideal bound can therefore be defended from A0 alone; the F3 bound is **UNKNOWN**, not 43% (which would incorrectly remove required VJP arithmetic) and not 1.32% (which would ignore state work inside denoiser/VJP).

The measured VJP component itself is clearly material (~42.6% of a guided complete-chunk median) and localized to 10 legal full-network VJPs; saved state is material in logical size. Under the Goal's explicit UNKNOWN branch, this warrants **one preregistered strong software A1**, but grants no hardware claim. No A0-minus-no-guidance comparison is used. Episode B remains sealed. DRAM traffic and PC-level bottleneck classification remain unmeasured at this gate, not inferred from saved-tensor bytes.
