# t128 first-entry correctness failure — no threshold modification

The S1 source patch remained opt-in/default OFF and OFF requalified all four discovery entries. A device list made from the current `ctx.done` passed all-active (1024), some-done (682), and zero-active (0) ascending-ID canaries. The fixed source/model/input snapshots and worker count were not changed after candidate data were seen.

At t128, B0 and S1 were each restored from the same full 138-array frozen entry and ran complete solver graphs. Both passed their respective parent-reference output gate; the paired comparison also had exact `nefc`, outer `solver_niter` and non-LS overflow, with no changed LS-bit worlds. Pairwise max normalized effective-output differences were qacc `5.565e-5`, qfrc_constraint `2.147e-4`, efc.Ma `3.211e-5`, and valid efc.force `2.617e-4`, each below the unchanged `5.301662e-4` per-world screen; global RMS screens also passed. The actual t128 input includes 24 no-constraint worlds and seven outer-iteration-limit worlds, and these were not removed.

The original R20R1 residual rule is final `gradient = sqrt(max(ctx.grad_dot,0))/(meaninertia*nv)` per world compared with the maximum of B0-only repeat values for that same entry plus the unchanged source tolerance `1e-6`. Before any S1 run, this Goal froze the envelope from the accepted five parent B0 repeats and a patched-source OFF B0 repeat. The t128 S1 result exceeded that envelope in 10 worlds; largest excess `1.572849763237015e-05`. The paired B0 itself exceeded the same frozen envelope in 11 worlds. Source-relation and final model-improvement residual checks passed; the failure is specifically final-gradient envelope stability. Raw arrays and all 10 offending-world records are in `CANDIDATE_T128_RESIDUAL_FAILURE_AUDIT.json` on node164.

This is not a valid basis to add the current B0 to the envelope after seeing S1, increase the tolerance, retry with another worker count, or time a numerically unqualified candidate. No performance samples were taken. The correct scientific reading is that the selected S1 cannot be qualified under the existing residual gate, while the B0-only envelope itself needs separate review before attributing fault to S1.
