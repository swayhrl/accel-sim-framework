# Single future validation proposal — not executed

Freeze one new B4 validation cohort of public JSON-schema structured-generation
prompts that is disjoint from C0, C1, and the already inspected H0. Bind model,
tokenizer, schemas, prompts, expected semantic checks, and every raw hash before
timing.

Use one persistent mixed runner with the unchanged `RULE_U01` threshold. Retain
the CPU legal-ID lists already produced by the mask worker; perform one fixed,
exact union-size reduction before the head; time that reduction and the branch
decision explicitly. On each step execute A3 only for fraction `<0.01`, else A0.

The primary boundary must include union publication, dispatch, any legal-ID or
mask materialization not already shared, H2D index/mask traffic, identical-mask
grouping, weight access, head compute, token selection/remapping, launches,
synchronization, and arm-transition/cache effects in the same trajectory. Pair
the live mixed runner against all-A0 with frozen warmup/repetition order and
preserve every step. Do not use per-step timing winners or retune the threshold.

This proposal is review-only. R22G performs no GPU execution.
