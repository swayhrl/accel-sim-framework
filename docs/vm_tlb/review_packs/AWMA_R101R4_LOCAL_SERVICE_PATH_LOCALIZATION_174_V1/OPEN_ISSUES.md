# Open issues and claim limits

- P0 and P1 are data-service diagnostic oracles.  They do not define a data
  source, physical storage, lookup energy, area, coherence protocol or
  implementable RTX4080 structure.
- This stage contains one accepted CONTEXT2 input.  It establishes neither
  workload generalization nor Native performance.
- The interventions are matched path-localization contrasts, but their cycle
  differences are not additive measurements of L1, request-ICNT, return-ICNT,
  ingress, L2 or cache latency fractions.
- P1 local service bypasses the downstream request/return trip by design while
  retaining normal L1 lookup, miss reservation/merge and fill completion.  It
  does not isolate an individual downstream component.
- Queue capacities 1/16 are frozen from accepted O2 observed maxima and were
  not scanned.  Absence of queue-full events in this input is evidence about
  this run only.
- Any Native realism check requires separate authorization and a newly defined
  metric contract.  This Goal neither runs nor prescribes a 109 experiment.
