# Open scientific boundaries

- Exact old-address and fill-generation survival was not captured in the accepted B16 run. Class occupancy and protected hits cannot substitute. The qualified Lane 1 observer implementation is prep evidence only; no full D1→D2 observer run is claimed here.
- Lane 4 has no preregistered numerical high/low/materiality cutoff and only a bounded UID168 repeat. A/B/C/D automatic promotion, statistical significance, whole-decode speedup and stable TPOT remain outside this result.
- The global protected→protected interval delta is not a class-1-specific victim trace. It supports competition as a live explanation, not unique causal attribution for each lost L0 line.
- M1F and `PRIORITY_STABLE` timing have not run. Their relative performance, exact protection occupancy and implementation costs remain open. The selector's static qualification does not supply these outcomes.
- Lane 6 FFN patch repair is independent and untouched. This review does not merge or consume its work.
