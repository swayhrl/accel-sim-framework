# R22F frozen measurement protocol

Frozen before new profile or complete-region timings. All CUDA/JIT and profiling hold `/data/c16/locks/c16_gpu_campaign.lock`, with acquire/release timestamps persisted per process. Each arm uses accepted frame55, float32, TF32 OFF, same OAM-S weights and official AOTInductor ASE CUDA model. Output checks and raw persistence follow synchronization and are symmetric, outside timers.

One NSYS scientific job maximum, `cuda,nvtx`, CUDA graph node trace where available. Profile warmup: two complete calls per qualified arm. Three blocks, four measured complete calls per arm/block. Three-arm block orders: `[A0,Aorder,Dready]`, `[Aorder,Dready,A0]`, `[Dready,A0,Aorder]`, repeated four times per block. If Aorder not qualified, two-arm orders alternate `[A0,Dready]` and `[Dready,A0]`. NVTX arm/block/repetition range encloses call and final CUDA synchronization. Do not use profiled kernel-duration sums as wall latency.

Uninstrumented complete energy+force: one process/session, all AOT models loaded before timing, five warmup calls per arm, then four groups with six formal calls per arm/group. Three-arm group orders: `[A0,Aorder,Dready]`, `[Aorder,Dready,A0]`, `[Dready,A0,Aorder]`, `[A0,Dready,Aorder]`, each repeated six cycles per group. Two-arm groups alternate `[A0,Dready]`, `[Dready,A0]`. Save all wall/CUDA-event samples, numerical pass, and each output. Group comparisons use medians/MAD; CLEAR requires all four groups same direction and median absolute arm gap >3 times the larger-arm group MAD estimate; otherwise MIXED or NO_RESPONSE as applicable. R21A historical samples are not pooled.
