# Validation and evidence boundary

`python3 validate_pack.py` checks required nonempty files, TSV schema/source coverage, exactly one allowed classification and the CPU/literature-only invariants. `sha256sum -c SHA256SUMS` checks the published review-pack bytes. The checks do not run any CUDA or author artifact.

The guard's `NEAREST_NEIGHBOR_CROWDED` label is a literature novelty decision for the **generic same-line→cache-mechanism narrative**, not an independent measurement of DeepSeek weight bytes, cache traffic or performance. Code URLs are pinned to source commits; arXiv versions are explicit. cuBLAS internals remain unknown.
