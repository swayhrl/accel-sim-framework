# Route B representative-kernel memory capture contract V1

Status: `PREPARED_NOT_AUTHORIZED_TO_RUN`.

Route B is the future capture of **all** static instructions that NVBit proves
are `GLOBAL` and `has_mref=true` within a preselected exact kernel function.
It is deliberately broader than Route A's single static PC but remains a
representative-kernel sample, not an ROI-wide memory characterization.

This local review found no phase-linked native kernel census for the exact
formal Llama identity `S0/B1/T128/Decode4`. Therefore the contract freezes
selection rules and two existing coverage anchors, but selects **zero**
duration-mass-qualified representative kernels. No GPU collection is permitted
until a matching census admits concrete selections through the rules here.

The prior formal `LLAMA_S0_FORMAL_V1/` result is retained unchanged and is the
only Route A evidence used here.
