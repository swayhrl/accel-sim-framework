# Future research questions

1. **Do real dense-weight and KV allocations exhibit the synthetic R1→R2 repeat-thrashing transition?** Evidence: P1/P2 move from resident-fast repeats to ~9–11 s repeats and >92 GB eviction at R2. AI property: whole-weight scans versus monotonic KV growth. Closest-work gap: prior UVM characterization is not bound to exact real-model tensor lifetimes. Validation: one instrumented local Llama run with explicitly managed weight/KV buffers, frozen tensor identities, migration bytes and per-step latency.
2. **When does real MoE routing lose the sparse-residency advantage?** Evidence: P3 keeps R3 repeat near 36 ms with ~2 MB DtoH while P1/P2 thrash. AI property: K-of-N rotating experts with locality. Closest-work gap: generic irregular-access work does not bind routing entropy, expert size and reuse period. Validation: an OLMoE tensor-level UVM bridge varying only prerecorded routing traces and reporting expert-resident migration per decode step.
