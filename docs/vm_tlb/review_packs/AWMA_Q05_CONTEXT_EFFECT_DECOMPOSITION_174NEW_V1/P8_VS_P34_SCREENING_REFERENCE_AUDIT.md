# P8 versus P34 screening/reference audit

P8 remains only a screening-prefix candidate. P34 remains the final realism reference because it contains all available real predecessors.

P8/P34 natural cycles differ by 36,690. Their target-only I0 cycles differ by 9,880. Both retain substantial translation sensitivity (P8 20.46%, P34 22.68%). This supports using P8 for future screening only after review, with P34 retained for final realism validation. It does not promote P8 as a replacement baseline or authorize a mechanism study.
