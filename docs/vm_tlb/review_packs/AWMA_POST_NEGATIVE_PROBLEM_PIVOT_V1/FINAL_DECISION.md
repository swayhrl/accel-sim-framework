# Final decision

`AWMA_POST_NEGATIVE_NO_NEW_PROBLEM_V1`

## Evidence result

The post-negative audit screened exactly three allowed families and advanced
one retrospective diagnostic hypothesis.

1. **Semantic object/lifetime interaction** is rejected. The accepted formal
   NVBit ingest preserves 1,503,232 active-lane address events as
   `UNKNOWN_RUNTIME`. The one simulator object map has KV/unknown counts but no
   matched weights/activation/lifetime contrast or attributed cycle cost.
2. **Cross-kernel context** is rejected as an architecture problem. Real-prefix
   Q05 cycles differ materially, but equal-overlap/equal-walk P8/P16 rows differ
   3.290% in the direction opposite L2-miss mediation. Existing observables do
   not localize the cause.
3. **Representation/runtime transformation** is rejected as already covered
   and underdetermined by accepted assets. AWQ S2 is valid standalone evidence,
   but raw 7B is OOM, the direct semantic run forbids timing use, and QServe,
   StreamDQ, and AWQ already target the broad dequantization/traffic space.

## Scientific boundary

Context-dependent replay remains a valid simulator-methodology warning, not a
new GPU architecture limitation. No hypothesis simultaneously has a material
cost, localized cause, realizable signal, independent validation sample, and
closest-work differentiation.

Accordingly:

- problem hypotheses advanced to prototype: `0`;
- simulator prototype runs: `0`;

- holdout mechanism runs: `0`;
- new Native runs: `0`;
- 109 invocations: `0`;
- new capture manifest: not emitted because no novelty-qualified question
  remains that new evidence could resolve.

The accepted UVM, resource-map, translation, and classic-dedup conclusions are
unchanged.
