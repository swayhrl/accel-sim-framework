# Scientific interpretation

The bounded trace and simulator use the same numeric global-address namespace for this admitted workload/configuration. The three preselected real addresses are exactly equal at every observed hop through L2 oracle lookup. Baseline coalescing and sector splitting remain deterministic transaction formation inside that namespace; they are not a virtual-to-physical remap or DRAM-partition address substitution.

The identity-generated sidecar is therefore qualified for later mechanism experiments, subject to the already frozen oracle mechanism and platform config. This result does not measure mechanism performance and does not authorize a baseline/candidate run or budget sweep.
