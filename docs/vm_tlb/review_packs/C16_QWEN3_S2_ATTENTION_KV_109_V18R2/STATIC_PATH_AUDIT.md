# Fresh static/path audit

Fresh SM89 SASS discovery was performed for the actual dedicated repeat-K direct-copy function, not by reusing a Qwen2 static set. The map contains 1,832 static instruction rows and the frozen MREF shard manifest contains 160 direct GLOBAL MREF indices. `GLOBAL_TO_SHARED`/LDGSTS count is zero for this function; direct GLOBAL and LDGSTS paths were independently audited. No other address-bearing special path was detected. Memory-control instructions are not counted as address-bearing evidence.

Every MREF shard has same-process `ADDRESS_CONTEXT`, exact replay identity, terminal-complete evidence and zero overflow. Zero-record shards are classified `ZERO_EXECUTION_PROVEN`; nonzero shards `EXECUTED_SHARD`. No cross-process VA merge, cross-path temporal order, or reuse-distance claim is made.
