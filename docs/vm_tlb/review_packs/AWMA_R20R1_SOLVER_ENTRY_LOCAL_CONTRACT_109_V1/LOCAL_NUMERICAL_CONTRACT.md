# R20R1 local solver-entry numerical contract — frozen before any candidate

Scope: one complete `solver.solve(m,d)` from a hash-frozen real B1024 entry, **not** the R20 32-step physical trajectory. The original R20 trajectory failure remains untouched. Input includes the original contact/EFC row order and floating parameters, sparse J/indices, M/factorization, warmstart, control and all 138 Data arrays; Model's 266 array hashes and fixed solver/options are checked separately. No contact sorting or CPU reconstruction is allowed. The in-situ full-step B0 exit and five isolated B0 replays plus one fresh graph at t128 passed this contract's B0-only validator. New entrances must use the same formula and undergo their own five B0 repeats before S1 exists.

Mandatory exact gates, independent of floating tolerance:

1. Model/options and all recorded solver-entry Data bytes must match the entrance's own frozen B0 payload; effective contact/EFC/J and world identity are not reconstructed or dropped. B0/S1 consume the same entrance, capacities, conditional graph policy, iterations=10, ls_iterations=20 and author-adjusted FP32 tolerance `1e-6`.
2. Per-world `nefc`, `solver_niter`, complete inherited-plus-new overflow bitmask, and absence of new true capacity overflow must be exact. `ITERATIONS` and `LS_ITERATIONS` are separate from capacity. Source `ctx.done` must be true after completion. Exact stop signature is required even when a world is limit-stopped; do not call `nsolving=0` mathematical convergence.
3. `qacc`, `qfrc_constraint`, `efc.Ma` and **only valid** `efc.force[w,:nefc[w]]` must be finite. Other zero-capacity/unused scratch bytes are not a numerical gate.

Floating-output rule, applied independently to each of those four fields against the entrance's B0 reference:

- Per world define its reference scale as `max(RMS(valid reference elements), 1)` in that field's own units. For each world, `max_abs(candidate-reference)/scale <= γ`, where `γ = (4445*eps32)/(1-4445*eps32) = 0.0005301662193351918`, `eps32=1.1920928955078125e-7` and 4445 is the frozen sparse Jacobian nonzero capacity. This is a conservative FP32 operation-count *engineering screen*, **not** a theorem that every Newton path has that error bound; no universal unit is assigned to mixed-coordinate arrays.
- Across all valid elements of each field, `RMS(candidate-reference)/max(RMS(reference),1) <= 100*eps32 = 1.1920928955078125e-5`. This second bound rejects diffuse systematic drift that a max-only perworld screen could miss. These values were derived from fixed source/input dimensions and FP32 precision before any S1 output or timing; they are not a multiplier of a measured maximum.
- The source identity `_qfrc_constraint_from_grad` gives `qfrc_constraint = efc.Ma - qfrc_smooth - ctx.grad_scale*ctx.grad`. Recompute in FP64 for diagnosis and require perworld max residual, normalized by `max(RMS(qfrc_constraint),1)`, no greater than `100*eps32`. This checks the complete-solver recovery output rather than accepting a stale qfrc buffer.
- Compare final context gradient `sqrt(max(ctx.grad_dot,0))/(meaninertia*nv)` and model-improvement `0.5*ctx.newton_decrement/(meaninertia*nv)` per world against the maximum of B0-only repeat values for that **same entrance**, plus the unchanged source solver tolerance `1e-6`. These are residual diagnostics, not claims that graph-end values always encode the exact stop-time predicate. The B0 envelope is frozen without seeing S1; no per-entry post-candidate adjustment.
