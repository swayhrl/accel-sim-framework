# Final decision

`R22E_EXISTING_EVIDENCE_DOES_NOT_JUSTIFY_NEW_DIAGNOSTIC`

Category A retains a real, strict cross-CTA conversion duplication: M64 75%, M32 50%, after intra-CTA staging is already performed by the strong fused kernel. This is a logical-work observation, not a cycle or physical-traffic saving. No accepted M32/M64 matched implementation times a complete, same-output operator with bounded shared decoded tiles plus publication, synchronization, fanout and reads. The separate M256 conversion-removal oracle is invalid-output and slower (1.538048 vs 1.270784 ms); the correct predecoded arm is faster (1.162752 ms) but changes representation/kernel and excludes materialization. Neither supplies that missing net contrast. The historical stop remains; the new family-first method merely removes low application coverage as a *sole* veto.

Category B has an accepted 18-point complete-operator matrix. Relative to RAW_FP16 on the same activation, AWQ up_proj M1 is 0.088424 vs 0.220928 ms, whereas M256 is 0.677573 vs 0.362578 ms; down_proj flips similarly (0.111420 vs 0.222373, then 0.500564 vs 0.392341 ms). q_proj M1 is approximately tied and noisy; M256 AWQ is slower. These are real implementation/shape responses, **not** bitwidth causality: weights, quantization/layout, dequant fusion, split-K scratch/reduction, and selected kernels change. M1023→1024 changes the AWQ path from quantized GEMM plus reduction to dequantize plus matmul. Up-proj NCU bytes exist, but are not tensor-attributed nor a timing decomposition; down-proj clean-point NCU is absent. An AWQ-versus-RAW proposal therefore lacks a single isolated intervention despite its local timing.

No additional proposal is entered in this Goal. The negative decision reflects the current counterfactual qualification gate, not a new performance measurement or universal closure of either family. Prior software work (MARLIN/QUICK/FLUTE/StreamDQ) overlaps low-bit dataflow and must be matched before any hardware claim. No old STOP label, baseline, or review pack was changed.
