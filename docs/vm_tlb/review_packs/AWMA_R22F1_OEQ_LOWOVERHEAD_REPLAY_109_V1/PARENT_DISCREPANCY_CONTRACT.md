# R22F1 frozen parent discrepancy and source/launch audit

Frozen before any R22F1 replay timing. Scientific parent `df0e8edd009ee1a56ba65b25b319e8a852f74d27`; R21A historical `MIXED/STOP` remains unchanged.

The pinned OpenEquivariance `TensorProductConv.forward` calls `libtorch_tp_jit::jit_conv_forward`. Its registered first-order autograd calls `jit_conv_backward`; no training step or double backward belongs to this energy→forces scope. `extension/torch_core.hpp` creates zeroed TP outputs/gradients. `extension/convolution.hpp` issues JIT main `forward`/`backward` and then `fixup_forward`/`fixup_backward`. In `loop_unroll_conv_atomic.cuh` those fixup bodies are empty but still launched; `loop_unroll_conv_det.cuh` has real workspace reduction/fixup. The OEQ PyTorch operator surface exposes complete convolution forward/backward but no direct supported fixup-only operator; optional direct-fixup timing must be marked unavailable unless an already-exposed exact call is found without source changes.

R22F's single NSYS bundle assigned 36 complete invocations and 4,332 GPU launches. The observed parent call pattern was two JIT forward and two first-order JIT backward calls per full OAM-S energy+force evaluation, with two forward and two backward fixup launches; R22F1 must capture all actual live callsites rather than assume this count. Parent source-attributed *profiled* Aorder→Dready: TP forward −1.792 µs, TP force backward −1.616 µs, gross TP −3.392 µs; real deterministic fixups +30.160 µs (forward +10.368, backward +19.776); resolved net target +26.752 µs. Atomic empty fixups themselves occupied 2.848 µs total in that profile, and direct JIT main kernels saved only 0.529 µs.

Parent *unprofiled* complete energy+force Aorder→Dready: Dready faster 13.955 µs / 2.878% under the four-group 3×MAD rule. A0→Dready complete wall remained MIXED. These parent levels are not arithmetically interchangeable: NSYS GPU kernel-duration sum is a profiled diagnostic, not an uninstrumented elapsed contribution. New R22F1 uses exact captured TP tensors and real upstream gradient with low-overhead CUDA events to test the family sign directly.
