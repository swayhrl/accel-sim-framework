# R22F1 frozen low-overhead replay protocol

Frozen before reading any new replay timing. The only science input is the non-timed, hash-closed real OAM-S sorted-graph TP capture; call multiplicity is the actual observed forward and force-VJP calls. Both OEQ arms use the same captured X/Y/W/rows/cols, and deterministic additionally receives the accepted sender transpose permutation. Construction/JIT/workspace allocation and any data transfer are outside timing. Float32, TF32 OFF, original `5e-5` forward/required-gradient contract.

Primary timer: one CUDA event pair on the same stream per bundle, synchronize after the end event, divide by replay count. For each actual callsite and arm: forward 10 warmup bundles; five formal groups; eight 32-replay formal bundles per group. Group arm order alternates Aorder→Dready and Dready→Aorder. Backward uses the captured real upstream gradient; fresh autograd forward states are built before each timed bundle. A non-timed 32-state feasibility/correctness canary for both arms/callsites selects backward mode before any arm timing: `BUNDLE32` if clean; otherwise `SINGLE20` with one backward replay per event pair and 20 formal samples/group. Backward also has ten warmups/arm/callsite. No mode change after timing begins.

For each group/arm/callsite/phase, calculate median and MAD of the fixed formal per-replay samples. Combined semantic-family group time is the sum of those medians over all real callsite multiplicities and phases; its conservative uncertainty estimate is the sum of their MADs. Aggregate response requires all five group gaps in the same direction and median absolute group gap >3× the larger-arm median aggregate-MAD estimate. A positive aggregate is not admitted if any callsite has a stable (five-group) opposite response exceeding 3× its own conservative MAD. Report per-callsite, forward, backward and combined actual µs/%; wall launch time is diagnostic only. Do not pool R22F NSYS or complete-model samples into this replay.

Optional direct fixup control is permitted only if pinned OEQ exposes the exact compiled fixup launch through a supported internal API without source alteration; otherwise `FIXUP_DIRECT_TIMING_NOT_AVAILABLE`. No profiler, Donline, old holdout, extra sample or second tensor source.
