# R19F2 Stage B frozen exact fused-software diagnostic contract

Stage A passed identity and left `17.29%` S1→D0 residual at the complete MLP boundary, with all three paired groups positive and gap >3×MAD; sharing recovered only `29.21%` of B0→D0 ideal MLP headroom. Thus Stage B is authorized by the Goal. This contract is frozen before implementing or timing the one allowed fused diagnostic.

Pinned TE v2.19.0 and independently inspected current-main source expose no directly reusable standalone one-launch **per-tensor E4M3 current-scaling amax+scale+cast** for this exact hidden X; the ordinary path has four kernels. The only new implementation is a small opt-in CUDA extension with one cooperative kernel launch, not a GEMM. It is limited to contiguous BF16 input of the frozen shape `[1,256,896]` and TE E4M3 output, with preallocated FP8 bytes/inverse-scale/amax buffers. The kernel initializes amax inside its launch, scans the complete tensor, grid-synchronizes, uses TE v2.19's round-to-nearest `__fdiv_rn(448.0f,amax)` scale and `__frcp_rn(scale)` inverse scale, and casts every BF16 value with CUDA's `__nv_fp8_e4m3` conversion. It must match TE's exact FP8 bytes and inverse-scale bytes; no approximate threshold is allowed. The current input is finite with nonzero amax, but the implementation also preserves TE's scale=1 handling for zero/nonfinite amax. If cooperative launch admission/compilation or exactness fails after bounded ordinary repair, stop as `R19F2_FUSED_COUNTERFACTUAL_NOT_QUALIFIED`—no second quantizer design.

The preallocated `te.Float8Tensor` wrapper around those bytes/scale is constructed **outside** formal timing. Each S2 measured call invokes the one fused quantizer kernel on the ready BF16 X, then feeds the same wrapper to the original cached-weight gate/up `te.Linear` consumers and unchanged `silu*up -> BF16 down_proj`. Buffer reuse is a stated part of this strong software counterfactual, not a pure kernel-service comparison. S1 and D0 remain the frozen Stage-A implementations. S2 must reproduce S1/D0 input bits/scale, gate output, up output and Region-M output bitwise before timing and again after timing. Gate/up consumer source, geometry and weights remain unchanged; no second NSYS capture or custom GEMM is permitted.

Stage B formal timing is unprofiled, 3 paired groups, 2 warmups and 5 formal samples per arm/group/region, both wall and CUDA-event, rotated arm and P/M region order as Stage A.
