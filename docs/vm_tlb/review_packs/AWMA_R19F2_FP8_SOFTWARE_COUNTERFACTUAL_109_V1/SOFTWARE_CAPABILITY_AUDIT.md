# Stage B source capability audit — current-scaling single-launch path

Pinned runtime/source is NVIDIA Transformer Engine v2.19.0 at `5e52befd5262c06289106338c308079d6adb391f`. For source capability **only**, a separate shallow current-main checkout was read at `a16bce3a647e4277b78c6426e70b9c6d4a1135dd`; the installed R19 environment, recipe, model and consumer were not switched.

The exact ordinary `Float8CurrentScalingQuantizer` path in both trees still performs distinct C++ calls in `transformer_engine/pytorch/csrc/quantizer.cpp`: `nvte_compute_amax_with_config`, `nvte_compute_scale_from_amax`, then `nvte_quantize_v2`. `transformer_engine/common/recipe/current_scaling.cu` has the **same SHA256** `690322481f4df93b3a40a1623343b2103d0f51143ed60764193c48d4e52ecf75` in pinned and current-main trees. Its reduction path launches `zero_amax_kernel`, `amax_kernel`, then `compute_scale_from_amax_kernel`; the cast is a separate launch. R19F2's sole NSYS witness measured exactly four preparation launches for one normal current-scaling input quantization.

The source does contain fused attention and other fused/transpose/FP4 operations, but those do not provide a direct standalone **per-tensor E4M3 amax + exact scale + cast in one launch** for this already-frozen Qwen hidden X while preserving the two TE Linear consumers. In particular, current-main's NVFP4 fused-amax paths are a different format/architecture and are not Ada FP8 evidence. No directly reusable exact one-launch public/source-supported standalone path was identified in this bounded audit.

The opt-in fallback permitted by the Goal is therefore one minimal **diagnostic** CUDA extension, not a TE/runtime replacement and not a new GEMM. It must use TE v2.19's current-scaling arithmetic exactly (`recipe_common.cuh::compute_scale_from_amax` and `utils.cuh::reciprocal<float>` semantics), generate matching E4M3 bytes/inverse scale on the real X, and feed an ordinary TE `Float8Tensor` to the unchanged gate/up `te.Linear` consumers. If exact bits/scales, launch count or output identity fail after bounded engineering repair, Stage B must stop as `R19F2_FUSED_COUNTERFACTUAL_NOT_QUALIFIED` rather than relaxing the contract.
