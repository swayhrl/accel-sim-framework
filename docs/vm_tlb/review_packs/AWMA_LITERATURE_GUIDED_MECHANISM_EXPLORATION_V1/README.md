# AWMA literature-guided mechanism exploration V1

Start with `REPORT.md`. The complete trial table is
`EXPLORATION_MATRIX.tsv`; machine-readable commands and gates are in
`RUN_RECEIPTS.json` and `CORRECTNESS_GATES.tsv`; durable raw locations and
hashes are in `RAW_DATA_INDEX.tsv`.

This pack records bounded discovery evidence. T0/T1/T2 are discovery inputs,
not holdouts. It does not promote a mechanism, merge into the frozen baseline,
or claim novelty or a paper conclusion.
