此图用于寻找最近邻，不作全球新颖性认证。每篇证据深度见SOURCE_REGISTER。

|---|---|---|

## Round03后的明确约束

Avatar已经包含OPT及三种CNN的FP16/FP32评估，不能将“加入LLM”当空白。37.2%来自主套件，ML子集相对CoLT7.1%；OPT大小/上下文/执行边界未披露。

MPW主模型translation-before-L1、Avatar主模型VIPT并行；MPW又有L1不先翻译敏感性。不能把不同路径的剩余headroom直接比较，也不能把论文模型当作已公开的Ada内部实现。

当前AWMA结果32854024…的0/80响应是强基线下时序干预，不是地址翻译运行时间比例。两篇补全文不授权重启机制开发，也不证明全部AI场景没有空间。

优先思考实际路径、窗口内不同页和请求突发、真实V2P映射稳定性、内容可压缩性、校验及时性与迁移失效。它们是问题筛选维度，不是本文提出的新算法。
