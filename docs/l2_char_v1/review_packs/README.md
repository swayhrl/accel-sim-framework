# L2 Characterization Review Packs

Each reviewable L2-characterization milestone keeps its normal source outputs
under `docs/l2_char_v1/` and also publishes an immutable compressed copy here.
The archive name carries the milestone and Framework commit.  Its internal
`CONTENTS.md` lists every included file and its SHA256.

Future milestone closeouts must follow the same rule: keep the canonical files
in their normal locations, then add a review-pack archive and update this
directory's index in the same scoped commit.
